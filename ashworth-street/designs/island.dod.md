Build this 2D top-down open-world island treasure-hunting exploration game. Every number below is a given value to write into the code as-is; none of them needs checking or deriving.

RECORDS: Player, Treasure, Clue, Guardian, Hazard, Resource, Region, Campfire, Tile, Storm, Clock.

PLAYER: x and y are the player’s centre in metres, 0 to 256, starting from the map generator’s spawn; heading is in radians, 0 facing right, starting 0; hp and maxHp are 20, 0 to 20; stamina and maxStamina are 100, 0 to 100; baseSpeed is 6.0 metres per second; sprintMultiplier is 1.6; swimMultiplier is 0.6; attackDamage is 5; attackRange is 1.8 metres; attackCooldown is 0.6 seconds; score is 0 treasure points; masterTreasures is 0 of 3; hasTempleKey, hasVolcanoKey, and hasShipKey are false; driftwood, coral, glowcap, and shard are 0; upgradeStamina, upgradeSpeed, and upgradeLantern are 0, each 0 to 3; hazardSlow is 0.0, 0 to 0.7; attackTimer is 0.0 seconds; dead is false.

TREASURE: id is 1 to 24; x and y are in metres; type is Common Chest, Rare Idol, Key Cache, or Master Chest; value is 10, 30, 30, or 100 treasure points; keyRequired is none, Temple Key, Volcano Key, or Ship Key; keyGrant is none, Temple Key, Volcano Key, or Ship Key; guarded is true only for Master Chest; revealed and collected are false. The fixed roster is 12 Common Chests with value 10, no keyRequired, and no keyGrant; 6 Rare Idols with value 30, no keyRequired, and no keyGrant; 3 Key Caches with value 30, no keyRequired, and keyGrant values of Temple Key, Volcano Key, and Ship Key; and 3 Master Chests with value 100, keyRequired values of Temple Key, Volcano Key, and Ship Key, and no keyGrant. Treasure id 19 grants Temple Key, id 20 grants Volcano Key, id 21 grants Ship Key, id 22 requires Temple Key, id 23 requires Volcano Key, and id 24 requires Ship Key.

CLUE: id is 1 to 12; x and y are in metres; targetTreasureId is 1 to 12, one per clue id; radius is 10 metres; read is false.

GUARDIAN: id is 1 to 6; x and y are in metres; type is Tide Crab, Shade Stalker, or Temple Sentinel; hp and maxHp; state is patrol, aggro, stun, or dead; speed and nightSpeed are in metres per second; aggroRange and nightAggroRange are in metres; attackRange is in metres; attackDamage; attackCooldown is in seconds; attackTimer is 0; aggroTimer is 0; stunTimer is 0; waypointA and waypointB are x and y pairs in metres; patrolDir is 1 or -1. The roster is 2 Tide Crabs with hp 10, speed 3.0, nightSpeed 3.0, aggroRange 7, nightAggroRange 7, attackRange 1.5, attackDamage 3, attackCooldown 0.8; 2 Shade Stalkers with hp 14, speed 2.2, nightSpeed 4.5, aggroRange 8, nightAggroRange 12, attackRange 1.8, attackDamage 4, attackCooldown 1.0; and 2 Temple Sentinels with hp 24, speed 2.5, nightSpeed 2.5, aggroRange 10, nightAggroRange 10, attackRange 9.0, attackDamage 5, attackCooldown 1.2.

HAZARD: id is 1 to 20; x and y are in metres; type is Thorn Tangle, Quicksand, Lava Vent, Tide Pool, or Lightning; radius is in metres; damage is in hp per second; slow is a 0 to 0.7 speed-reduction value; active is a boolean; activeTimer is 0 seconds; offset is 0 seconds. The fixed initial roster is 3 Thorn Tangles with radius 3, damage 2, slow 0.4, and active true; 2 Quicksands with radius 2.5, damage 0, slow 0.7, and active true; 3 Lava Vents with radius 2, damage 8, slow 0, active for 5 seconds of every 20 seconds based on offset; and 2 Tide Pools with radius 3, damage 1, slow 0.4, active for 30 seconds of every 60 seconds based on offset. Lightning hazards created by weather have id 11 to 20, radius 3, damage 50, slow 0, and active for 0.2 seconds.

RESOURCE: id is 1 to 48; type is Driftwood, Coral, Glowcap, or Shard; x and y are in metres; collected is false. The fixed roster count is 14 Driftwood, 12 Coral, 10 Glowcap, and 12 Shard.

REGION: id is 1 to 8; name; x and y are in metres; radius is in metres; type. The fixed roster is 1 Forest at 80,128 with radius 30; 2 Dune at 128,80 with radius 24; 3 Crags at 176,128 with radius 22; 4 Shipwreck at 96,96 with radius 18; 5 Temple at 128,108 with radius 16; 6 Volcanic at 176,176 with radius 20; 7 Lagoon at 88,176 with radius 16; and 8 Cove at 176,96 with radius 16.

CAMPFIRE: id is 1 to 4; x and y are in metres. The fixed starting positions are 1 at 128,192, 2 at 88,128, 3 at 168,128, and 4 at 128,72, each moved to the nearest land tile by the map generator.

TILE: id is 0 to 16383 for a 128 by 128 grid; x and y are the tile’s centre in metres, 0 to 256; type is water, beach, forest, dune, crags, temple, volcanic, lagoon, or cove; revealed is false.

STORM: active is false; x and y are in metres, starting 128,128; radius is 40 metres; lightningTimer is 0 seconds; activeTimer is 0 seconds.

CLOCK: time is 0 seconds; dayLength is 120 seconds; nightStart is 45 seconds; nightEnd is 95 seconds; stormInterval is 120 seconds; stormDuration is 20 seconds.

SYSTEMS: MAP GENERATOR, EXPLORATION, MOVEMENT, COMBAT, GUARDIAN AI, TREASURE, CLUE, HAZARD, WEATHER, CAMPFIRE, GAME STATE.

MAP GENERATOR: The map is a SEEDED GENERATOR for a 256 by 256 metre world divided into 128 by 128 tiles of 2 metres. It first creates a land mask using the centre at 128,128 and seeded value noise with three octaves of amplitudes 8, 3, and 1 metres and cell sizes 24, 12, and 6 metres; a tile is land when its distance from the centre plus that noise is 62 metres or less. Default land type is beach for tiles 54 to 62 metres from the centre, forest for 44 to 54 metres, dune for 34 to 44 metres, and forest for 0 to 34 metres; water is used elsewhere. Then each tile inside a region’s radius is overwritten with that region’s type, using the nearest region centre when radii overlap. The generator moves any region centre that is water to the nearest land tile. It then places four campfires at the Campfire record positions, 48 resources with 14 Driftwood in Cove or Shipwreck, 12 Coral in Cove or Lagoon, 10 Glowcap in Forest or Lagoon, and 12 Shard in Temple, Crags, or Volcanic, choosing seeded land tiles at least 2 metres from other content; if a type cannot place all items, it re-rolls. It places 24 treasures as listed: ids 1 to 12 are Common Chests with 3 in Forest, 3 in Dune, 3 in Cove, and 3 in Lagoon; ids 13 to 18 are Rare Idols with 2 in Forest, 2 in Dune, and 2 in Shipwreck; id 19 is a Key Cache granting Temple Key in Dune; id 20 is a Key Cache granting Volcano Key in Forest; id 21 is a Key Cache granting Ship Key in Crags; id 22 is a Master Chest requiring Temple Key in Temple; id 23 is a Master Chest requiring Volcano Key in Volcanic; and id 24 is a Master Chest requiring Ship Key in Shipwreck. It places 12 clues, one targeting each treasure id 1 to 12, on land between 8 and 20 metres from the target. It places 10 initial hazards: 3 Thorn Tangle in Forest, 2 Quicksand in Lagoon, 3 Lava Vent in Volcanic, and 2 Tide Pool in Cove. It places 6 guardians: 1 Tide Crab within 6 metres of treasure id 24 and 1 Tide Crab in Forest, 1 Shade Stalker within 6 metres of treasure id 23 and 1 Shade Stalker in Dune, 1 Temple Sentinel within 6 metres of treasure id 22, and 1 Temple Sentinel in Crags. It chooses the player spawn as the land tile nearest 128,200. The VERIFIER requires all eight region centres on land, all content on land, no two content centres within 2 metres, every treasure reachable from spawn by a path over land tiles, and all 24 treasures, 12 clues, 10 hazards, 6 guardians, 48 resources, and 4 campfires present; if any check fails, the generator re-rolls with the next seed.

EXPLORATION: Each simulation tick, the game reveals every Tile whose centre lies within 12 + 4*Player.upgradeLantern metres of the player; during night, as defined by WEATHER, the radius is reduced by 4 metres but never below 8 metres, and each affected Tile.revealed becomes true. If the player is within 2 metres of a Campfire, that campfire also reveals tiles within 20 metres.

MOVEMENT: The keyboard binds W and Up to up, S and Down to down, A and Left to left, D and Right to right, Shift to sprint, Space to attack, E to interact, M to toggle the map, and R to restart; on touch, the left half of the screen is a virtual joystick for movement, the right half taps to attack, and a right-bottom button interacts. When an input vector exists, Player.heading becomes the vector’s angle. Effective speed is (6.0 + 0.5*Player.upgradeSpeed) multiplied by terrain, hazard, and sprint factors. Terrain multipliers are water 0.6, beach 1.0, cove 1.0, forest 0.9, dune 0.85, crags 0.8, temple 1.0, volcanic 0.9, and lagoon 0.7. If Player.hazardSlow is greater than 0, speed is multiplied by (1 - Player.hazardSlow). If the player is on land, sprinting with Shift when Player.stamina is greater than 10 multiplies speed by 1.6 and drains 20 stamina per second; if the player is in water, speed uses the water multiplier and drains 10 stamina per second; otherwise stamina regains 12 per second. Effective maximum stamina is 100 + 20*Player.upgradeStamina. If the player is in water with stamina 0, Player.hp decreases 2 per second. Player.x and Player.y move by effective speed times dt and are clamped to 0 and 256.

COMBAT: When Space is pressed and Player.attackTimer is 0, Player.attackTimer becomes 0.6 seconds and the player attacks. All Guardians within Player.attackRange metres and inside a 120 degree arc centred on Player.heading lose 5 hp, become state stun with stunTimer 0.4 seconds, and are knocked back 1 metre away from the player. If a Guardian’s hp reaches 0, its state becomes dead and Player.shard increases by 1. Guardian attacks are handled by GUARDIAN AI.

GUARDIAN AI: Each tick, if a Guardian is dead it does nothing; if stunTimer is greater than 0 it decreases by dt and the guardian does not move or attack. A Guardian’s effective speed and aggro range are its night values during night, otherwise its day values; in water both are multiplied by 0.6. In state patrol, it moves toward waypointA or waypointB at half effective speed and toggles the target when within 0.5 metres; if the player is within effective aggro range, it becomes aggro with aggroTimer 5 seconds. In state aggro, if the player is farther than effective aggro range plus 4 metres, aggroTimer decreases by dt and the state becomes patrol when aggroTimer reaches 0; otherwise it chases the player at effective speed. If the player is within attackRange and attackTimer is 0, Player.hp decreases by attackDamage and attackTimer becomes attackCooldown.

TREASURE: When the player presses E within 1.5 metres of an uncollected Treasure, the game checks the key. If keyRequired is none, or the corresponding Player key is true, Treasure.collected becomes true, Player.score increases by Treasure.value, and if keyGrant is not none the corresponding Player key becomes true. If Treasure.type is Master Chest, Player.masterTreasures increases by 1. If the key is missing, the treasure does not change and the screen shows a locked message for 1 second.

CLUE: When the player presses E within 1.5 metres of an unread Clue, Clue.read becomes true. If its target Treasure is not collected, that Treasure.revealed becomes true and the minimap shows a 10 metre ring at the target’s location; if the target is already collected, the clue has no other effect.

HAZARD: At the start of each tick, Player.hazardSlow is set to 0.0. Each tick, every active Hazard updates its cycle: Thorn Tangle and Quicksand remain active; Lava Vent is active for 5 seconds of every 20 seconds based on its offset; Tide Pool is active for 30 seconds of every 60 seconds based on its offset; Lightning is active for 0.2 seconds and then deactivates. For each active Hazard whose centre is within its radius of the player, Player.hazardSlow becomes the smaller of 0.7 and its current value plus Hazard.slow, and Player.hp decreases by Hazard.damage times dt. A Lightning Hazard therefore removes 10 hp if the player stands inside it for its full active time.

WEATHER: Clock.time increases by dt each tick. The current phase is Clock.time modulo 120; night is true when phase is 45 or greater and less than 95. When a simulation tick crosses a multiple of 120 seconds and Storm.active is false, Storm.active becomes true, Storm.activeTimer becomes 20, Storm.x and Storm.y become a seeded random land tile inside one of the eight region centres, Storm.radius is 40, and Storm.lightningTimer is 0. While active, Storm.activeTimer decreases by dt; every 2 seconds based on Storm.lightningTimer, the game creates a Lightning Hazard on a seeded random land tile within 40 metres of Storm.x and Storm.y. When Storm.activeTimer reaches 0, Storm.active becomes false.

CAMPFIRE: While the player is within 2 metres of a Campfire, Player.hp increases by 2 per second until maxHp. Pressing 1, 2, or 3 near a campfire attempts an upgrade if the level is below 3 and resources are sufficient: 1 costs 5 Driftwood and 2 Glowcap, increases Player.upgradeStamina by 1, and reduces both counts; 2 costs 6 Driftwood and 3 Coral, increases Player.upgradeSpeed by 1; 3 costs 4 Glowcap and 2 Shard, increases Player.upgradeLantern by 1. If resources are insufficient or the level is 3, nothing changes.

GAME STATE: If Player.hp is 0 or less, Player.dead becomes true and the screen becomes game over. If Player.masterTreasures is 3 or more, the screen becomes win. Restart resets all records with the same seed; after win, continuing returns to the game with the same records.

CORE LOOP: The player uses MOVEMENT and EXPLORATION to cross the island, reads CLUEs and gathers RESOURCE pickups, spends resources at CAMPFIRE to grow stamina, speed, and lantern range, then uses improved movement and COMBAT to survive HAZARDS, WEATHER, and GUARDIAN AI, collects TREASURES to gain score, keys, and masterTreasures, repeats in new regions, and wins by collecting all three Master Chests; score and upgrades grow each cycle, keys unlock the final masters, and the win screen is the goal.

DEBUG API: The game installs window.__game with start(), which enters play from the title without a click and returns getState(); step(dt, n), which advances the simulation n ticks of dt seconds without waiting for real time, then draws once and returns getState(); setTime(t), which advances to t seconds without drawing and returns getState(); seed(n), which reseeds every generator and returns {seed:n}; getState(), which returns the fields of Player, Treasure, Clue, Guardian, Hazard, Resource, Region, Campfire, Tile, Storm, and Clock as plain data, including tilesRevealedCount, night, tileAtPlayer, and mapValid; map.reroll(), which regenerates the current seed’s world and returns {regions:8}; exploration.revealAt(x,y,radius), which reveals tiles within radius and returns tilesRevealedCount; movement.setPlayerPosition(x,y), which sets Player.x, Player.y, and Player.heading to 0 and returns the new position; movement.setInput(dx,dy), which stores the held movement vector and returns it; combat.attack(), which performs one player attack immediately and returns the ids of guardians damaged; guardian.spawn(type,x,y), which adds a Guardian of that roster type and returns its id; guardian.setGuardianState(id,state), which sets that state and returns the guardian’s id and state; treasure.spawn(type,x,y,keyRequired,keyGrant), which adds a treasure and returns its id; treasure.collect(id), which applies the TREASURE rule and returns the player’s score, keys, and masterTreasures; clue.spawn(targetTreasureId,x,y), which adds a clue and returns its id; clue.read(id), which applies the CLUE rule and returns the target treasure’s revealed field; hazard.spawn(type,x,y), which adds a hazard and returns its id; hazard.activate(id,seconds), which sets that hazard active for seconds and returns its id; weather.setDayPhase(seconds), which sets Clock.time to that phase within a day and returns night; weather.startStorm(), which makes Storm.active true with activeTimer 20 and returns storm’s x and y; campfire.upgrade(type), which applies a campfire upgrade for stamina, speed, or lantern and returns the three upgrade levels; game.setResources(driftwood,coral,glowcap,shard), which sets those player counts and returns them; game.setPlayerHealth(value), which sets Player.hp and returns it; game.forceWin(), which sets masterTreasures to 3 and returns the screen; and game.forceLose(), which sets hp to 0 and returns the screen. Every call is synchronous and returns only plain data, and with seed and step the same sequence of calls always yields the same state.

SCREENS: The state machine is title → game → pause → game over, and game → win. The title screen shows the game name, an island scene, and the controls: WASD and arrows move, Shift sprint, Space attack, E interact, 1/2/3 upgrade near campfire, M map, R restart, and touch left joystick plus right attack and interact; Enter or the Start button leads to game. In game, Escape opens pause; pause shows Resume and Restart, Resume or Escape returns to game, and Restart goes to game with the same seed. Game over offers Restart, with R or button. Win offers Continue and Restart; Continue returns to game with the same records, and Restart resets. The HUD reads from Player for hp, stamina, score, masterTreasures, keys, and resource counts; from Clock for day or night; from Tile.revealed for the minimap; and from nearby records for the current prompt, such as a Treasure, Clue, or Campfire.

AUDIO: All sound is generated with the Web Audio API. A soft footstep plays every 0.4 seconds while the player is moving, with a lower pitch in water. A whoosh plays when Player.attackTimer is set by COMBAT. A dull thud plays when a Guardian.hp decreases, and a crack plays when a Guardian becomes dead. A bright chime plays when Treasure.collected becomes true, a key jingle plays when a key is granted, and a page turn plays when Clue.read becomes true. A low warning plays when an active Hazard overlaps the player, and a thunder boom plays when a Lightning Hazard is created. A crackling loop plays while the player is within 2 metres of a Campfire, and a success chime plays when CAMPFIRE grants an upgrade. A night hum starts when night becomes true and a day birdsong starts when night becomes false.
