Build this 2D top-down survival game on a derelict space station where the player scours a generated station map for oxygen, parts, and medkits while a broken defense AI hunts through the corridors, sections flood and leak radiation, and the goal is to reach and launch the escape pod. Every number below is a given value to write into the code as-is; none of them needs checking or deriving.

RECORDS: Player, Room, Item, Threat, PowerSection, StationAI, GameState.

PLAYER: x (float, tile coordinate, start 50.0), y (float, tile coordinate, start 50.0), oxygen (float, 0–100, start 100, units: percent), health (float, 0–100, start 100, units: percent), radiation (float, 0–100, start 0, units: percent), suitIntegrity (float, 0–100, start 100, units: percent), inventory (array of Item, max 6 entries), facing (enum: up, down, left, right, start down), speed (float, 4.0 tiles per second), currentRoomId (int, the room whose bounds contain the player).

ROOM: id (int, 0–19), name (string), x (int, tile), y (int, tile), w (int, tiles), h (int, tiles), type (enum: hub, storage, engineering, medbay, living, reactor, observation, airlock, escapePod, corridor), oxygenLevel (float, 0–100, start 100, units: percent), floodLevel (float, 0–100, start 0, units: percent), radiationLevel (float, 0–100, start 0, units: percent), powered (bool, start false), damaged (bool, start false), visited (bool, start false), locked (bool, start false), items (array of Item). The roster of room types and their default oxygen, flood, radiation, and powered values: hub (100, 0, 0, true), storage (80, 0, 0, false), engineering (70, 20, 0, false), medbay (90, 0, 0, false), living (85, 0, 0, false), reactor (60, 10, 40, false), observation (95, 0, 0, false), airlock (50, 0, 10, false), escapePod (40, 0, 0, false), corridor (90, 0, 0, true).

ITEM: type (enum: oxygenTank, medkit, food, water, battery, sparePart, tool, radShield), quantity (int, 1). The roster: oxygenTank (restores oxygen +50, cap 100), medkit (restores health +30, cap 100), food (restores health +10, cap 100), water (reduces radiation −15, floor 0), battery (powers a PowerSection for 90 seconds), sparePart (consumable, required for repairs), tool (durable, required to unlock doors and repair pod), radShield (reduces radiation −30, floor 0, one-time use).

THREAT: id (int), type (enum: drone, floodSurge, radBurst), x (float, tile), y (float, tile), active (bool), timer (float, seconds remaining), damage (float, per tick), speed (float, tiles per second). Drones start with damage 30 (per contact tick, 1 tick per 0.5 seconds), speed 2.5. Flood surges apply damage 5 per second while player is in the room. Rad bursts apply damage 5 radiation per second while player is in the room.

POWERSECTION: id (int), roomId (int), level (float, 0–100, units: percent), timer (float, seconds of battery power remaining), manualOn (bool, set by player with battery).

STATIONAI: state (enum: dormant, patrolling, alert, hunting), x (float, tile), y (float, tile), speed (float, tiles per second, base 3.0 patrol / 4.5 hunt), lastSeenX (float), lastSeenY (float), lossTimer (float, seconds since player was last in sight, reset to 0 on detection, counts up to 15.0 to return to patrol), patrolRoute (array of room ids, 4 entries), coreDestroyed (bool, start false).

GAMESTATE: elapsed (float, seconds), escapePodRepaired (bool, start false), escapePodReady (bool, start false), roomsExplored (int, 0), threatsSpawned (int, 0).

SYSTEMS: SEEDED GENERATOR, SURVIVAL, EXPLORATION, RESOURCES, POWER GRID, THREATS, STATION AI, PLAYER CONTROLS.

SEEDED GENERATOR: The station is a 100-by-100 tile grid. Place the central hub (type hub, 12×12) at tiles (44, 44) through (55, 55). From the hub centre (49.5, 49.5) extend 8 primary corridors (type corridor, 2 tiles wide, 6 tiles long) at angles 0°, 45°, 90°, 135°, 180°, 225°, 270°, 315° (measured from north, clockwise). At the far end of each corridor place a room of 7×7 tiles. Assign the 8 outer rooms in clockwise order from north: storage, engineering, medbay, living, reactor, observation, airlock, escapePod. The escapePod room is the 8th (angle 315°, upper-left area) and is always locked at start. Mark exactly 4 of the 8 outer rooms as damaged (chosen by seed: the 1st, 3rd, 5th, and 7th in clockwise order, i.e. storage, living, observation, airlock). Damaged rooms have their floodLevel set to 50 and oxygenLevel reduced to 50. Corridors adjacent to damaged rooms have oxygenLevel 70. Place items by room type: storage gets 2 oxygenTank + 1 food; engineering gets 2 sparePart + 1 tool; medbay gets 2 medkit + 1 water; living gets 1 food + 1 water + 1 radShield; reactor gets 1 battery + 1 sparePart; observation gets 1 oxygenTank; airlock gets 1 medkit + 1 battery; escapePod gets 1 sparePart + 1 oxygenTank. The hub starts powered (powered true, all corridors powered true). All other rooms start unpowered. The escapePod room starts locked true. VERIFIER: exactly 1 hub, exactly 8 corridors, exactly 8 outer rooms, exactly 4 damaged rooms, escapePod is locked, total item count is 19, every corridor connects hub to exactly one outer room. Re-roll with the next seed if any check fails.

SURVIVAL: Every 0.25 seconds tick: if the current room's oxygenLevel is below 60, reduce player.oxygen by (1.0 × (60 − room.oxygenLevel) / 60) per tick; if room.oxygenLevel is 0, reduce by 4.0 per tick. If room.radiationLevel is above 0, increase player.radiation by (room.radiationLevel / 10) per tick, then multiply the increase by (1.0 − player.suitIntegrity / 200.0) so a full suit halves the dose and a destroyed suit doubles it. If player.radiation is above 70, reduce player.health by 2.0 per tick. If player.oxygen is below 20, reduce player.health by 3.0 per tick. If room.floodLevel is above 60, reduce player.health by 4.0 per tick and reduce player.oxygen by 1.0 per tick. If player.suitIntegrity is below 30 and the room has radiationLevel above 0, reduce player.suitIntegrity by 1.0 per tick (the suit is degrading). If player.health reaches 0 or player.oxygen reaches 0, the game is over (death). All caps: oxygen 100, health 100, radiation 0, suitIntegrity 100.

EXPLORATION: The player moves within the 100×100 grid. The player cannot enter a tile that is a wall (outside any room or corridor bounding box). If a room is locked, the player cannot enter its tiles. If a room is not powered and the player has not yet visited it, the player enters it but it is rendered fully dark (visibility limited to 3 tiles around the player). If a room is powered, visibility is the full room. The player's currentRoomId updates each tick to the room whose bounds contain the player's x,y. Corridors are 2 tiles wide; the player moves smoothly at player.speed tiles per second in the facing direction. The player cannot pass through a locked room's boundary tiles.

RESOURCES: When the player presses the interact key (E or tap-hold) while overlapping an Item tile, if player.inventory length is below 6, remove the Item from the room's items array and append it to player.inventory. If inventory is full, nothing happens and the item remains. The player can press 1 through 6 to use the item in that slot: oxygenTank adds 50 to player.oxygen (cap 100) and removes the item; medkit adds 30 to player.health (cap 100) and removes; food adds 10 to player.health (cap 100) and removes; water subtracts 15 from player.radiation (floor 0) and removes; radShield subtracts 30 from player.radiation (floor 0) and removes; battery and tool and sparePart are not consumed by use but are held. If the player is in a room with a locked door (a wall tile on the boundary) and presses interact while holding a tool in any slot, the door unlocks (room.locked becomes false) and the tool is removed from inventory. The escapePod room, once unlocked, requires the player to interact again while holding a sparePart and a tool to set escapePodRepaired true (both consumed). Once escapePodRepaired is true, the player interacts one final time to set escapePodReady true, which triggers the win.

POWER GRID: Each PowerSection maps to one Room. A section is lit (powered true) if manualOn is true or its battery timer is above 0. Battery use: the player presses interact while standing in a room with a battery in inventory; the room's PowerSection gets manualOn true and timer 90.0. Each tick, if timer is above 0, subtract 0.25 (one tick's worth), and when it hits 0 set manualOn false. If a room becomes unpowered (powered false and no battery), its visibility drops to 3 tiles, and if the player is inside, oxygen drain accelerates as in SURVIVAL (oxygenLevel effectively drops to 40). The hub and all corridors are permanently powered (they cannot be disabled).

THREATS: Every 20 seconds, if threatsSpawned is below 12, spawn one Threat. The type is chosen by seed cycle: drone, floodSurge, radBurst, drone, floodSurge, radBurst, and so on. A drone spawns at a random unvisited room's entrance corridor tile, active true, and moves along corridors toward the player's current position at 2.5 tiles per second. A drone deals 30 damage to player.health every 0.5 seconds while within 1.0 tile of the player. A floodSurge targets a random damaged room, sets that room's floodLevel to 100 for 15 seconds, then decays back to 50 over 10 seconds. A radBurst targets the reactor room, sets its radiationLevel to 80 for 12 seconds, then decays back to 40 over 8 seconds. Drones are destroyed if the player presses interact while within 1.5 tiles and holding no items in use (a "shove" action); the drone's active becomes false and it is removed. If the Station AI core is destroyed, no more drones spawn.

STATION AI: The AI is a single entity (one StationAI record) that starts in state dormant. It awakens (state becomes patrolling) the first time the player enters any outer room. While patrolling, it moves along its patrolRoute (a fixed loop of 4 room centres chosen by seed from the outer rooms, excluding the escapePod room) at speed 3.0. If the player is in the same room as the AI, or in a corridor within 3.0 tiles of the AI, the AI sets lastSeenX and lastSeenY to the player's position, state becomes alert, and speed becomes 4.5. After 2.0 seconds of alert, state becomes hunting: the AI moves directly toward lastSeenX/lastSeenY at 4.5. If the player is not detected for 15.0 consecutive seconds (lossTimer counts up each tick, resets to 0 on detection), the AI returns to patrolling at 3.0. The AI deals 40 damage to player.health if it touches the player (within 1.0 tile). The AI is permanently disabled if coreDestroyed is true: set state to dormant, remove the entity. The AI core is a specific interactable object in the engineering room; the player must hold a tool and 2 spareParts to destroy it (all three consumed, coreDestroyed true).

PLAYER CONTROLS: WASD and the arrow keys both move the player in the up, down, left, right directions (facing updates to the last pressed direction). E or tap-hold (0.5 seconds) triggers interact (item pickup, door unlock, battery placement, AI core, escape pod). Number keys 1 through 6 use the item in that inventory slot. On touch, a virtual d-pad on the lower-left moves the player, and a single action button on the lower-right triggers interact; tapping an item icon in the HUD uses it. Escape opens the pause overlay. P resumes from pause. Q quits to title from pause. R restarts from the game-over or win screen.

CORE LOOP: Each minute the player moves through corridors (EXPLORATION) into new rooms, checks and manages their oxygen, health, radiation, and suit (SURVIVAL), picks up items and uses them (RESOURCES), powers up dark rooms to see further (POWER GRID), dodges or destroys incoming drones and avoids flooding and radiation rooms (THREATS), and outruns the Station AI as it hunts them (STATION AI). What grows: the inventory fills, more rooms are visited, the AI's patrol tightens around the player's location. What unlocks: powering rooms reveals new corridors and items; unlocking the escapePod room requires the tool; repairing the pod requires a sparePart; the AI core, once destroyed, removes the biggest threat. The win is reaching the escapePod room, unlocking it, repairing the pod, and launching it. The loss is oxygen or health hitting zero.

DEBUG API: start() enters play from the title screen without a click and returns the initial GameState fields. step(dt, n) advances the simulation n ticks of dt seconds without waiting for real time, then draws once, and returns the GameState fields. setTime(t) advances the clock to t seconds without drawing and returns the GameState fields. seed(n) reseeds every generator (the SEEDED GENERATOR re-runs with the new seed) and returns the new room list. getState() returns player.oxygen, player.health, player.radiation, player.suitIntegrity, player.x, player.y, player.facing, player.inventory (array of item type strings), player.currentRoomId, all room fields (id, type, oxygenLevel, floodLevel, radiationLevel, powered, damaged, visited, locked, items), the StationAI state, x, y, coreDestroyed, lossTimer, every Threat (id, type, x, y, active, timer), every PowerSection (id, roomId, level, timer, manualOn), and the GameState fields (elapsed, escapePodRepaired, escapePodReady, roomsExplored, threatsSpawned). spawnDrone(x, y) creates a new Threat of type drone at the given tile coordinates, active true, and returns its id. setRoom(roomId, floodLevel, radiationLevel, oxygenLevel) overwrites the named fields of that room and returns the updated room. giveItem(type) appends an item of the given type to the player's inventory if there is room and returns the inventory array. setPower(roomId, on) sets the room's PowerSection manualOn to the given boolean and returns the section. wakeAI() sets the StationAI state to patrolling immediately and returns the AI state. triggerFlood(roomId) sets the given room's floodLevel to 100 and returns the room. triggerRad(roomId) sets the given room's radiationLevel to 80 and returns the room.

SCREENS: title (black background, the word "DERELICT" in large white text, below it "WASD / Arrows: Move, E: Interact, 1-6: Use Item, Esc: Pause", below that "Press Enter or tap to begin") → game (full-screen top-down station view with HUD overlay) → pause (dimmed game view, "PAUSED" centred, "P: Resume, Q: Quit to Title") → game over (red-tinted overlay, "SIGNAL LOST" or "OXYGEN DEPLETED" depending on cause, "Press R to retry") → win (white flash then "ESCAPE POD LAUNCHED", stats: time survived, rooms explored, threats destroyed, "Press R to play again"). Escape during play leads to pause. P in pause leads back to game. Q in pause leads to title. R on game over or win leads to title (which auto-calls start on Enter). The HUD shows: top-left, oxygen as a blue bar (0–100 from player.oxygen), health as a red bar (0–100 from player.health), radiation as a green bar (0–100 from player.radiation), suit integrity as a grey bar (0–100 from player.suitIntegrity); top-right, a small clock (GameState.elapsed in mm:ss) and the current room name (Room.name from the room whose id is player.currentRoomId); bottom-left, 6 item slots showing the icon and count of each Item in player.inventory; bottom-right, a small minimap showing the 100×100 grid with visited rooms in grey, the current room in blue, the escapePod room in red if visited, and the AI as a white dot (StationAI.x, y).

AUDIO: A low continuous hum (60 Hz sine wave, volume 0.05) plays while the player is in any room with oxygenLevel above 40, representing life support. An oxygen warning: a pulsing 800 Hz beep (0.1 s on, 0.4 s off) plays whenever player.oxygen is below 25. A drone alert: a rising 400-to-900 Hz sweep (0.3 s) plays the moment the StationAI state changes to alert or hunting. A drone hit: a 120 Hz square wave burst (0.15 s) plays each 0.5 s tick a drone deals damage. A flood rumble: a 40 Hz sawtooth with random noise (volume 0.1) plays while the player is in a room with floodLevel above 60. A radiation crackle: a burst of white noise (volume 0.08, 0.2 s) plays every 1.0 s while player.radiation is increasing. A power-on pop: a 2000 Hz sine blip (0.05 s) plays when a room's PowerSection manualOn becomes true. A power-off buzz: a 100 Hz square (0.3 s) plays when manualOn becomes false or the battery timer hits 0. An item pickup chime: a 1200 Hz sine (0.1 s) plays on successful item pickup. An escape pod launch: a 50 Hz rumble (2.0 s) fading to silence, plays the moment escapePodReady becomes true and the win screen appears.
