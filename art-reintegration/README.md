# art, back into the spec-driven build

Status: single-run
Control: spec-skeleton overnight builds 2026-09-14, all code-drawn (the integrator ruled "all assets generated in code")

## Purpose

The builds Nick judged the winners drew every sprite and tile in code and synthesised every
sound. The integrator made that ruling on a false premise (it did not know generate_media
existed), and art has been the pipeline's weakest leg. Nick: "if we can win without generating
assets, imagine what happens when we do generate amazing assets."

## Hypothesis

Tell the design team what the builder can ask for (generate_media kinds, compose_world) so the
visual doc plans real assets and the integrator carries them, then build. Measured: assets asked
for and loaded, Nick's read against the code-drawn twin of the same ask. Idea failure: the art
lands but the game reads worse (mismatched style, sprites the code-drawn version handled better),
or the builder burns turns on asset plumbing.
