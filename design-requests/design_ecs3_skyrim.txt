Build this 3D open-world fantasy RPG where the player explores a generated land, fights monsters, talks to villagers, levels skills, and clears a final dragon quest. Every number below is a given value to write into the code as-is; none of them needs checking or deriving.

RECORDS: Player, World, Region, Enemy, NPC, Item, Quest, Skill, Loot.

PLAYER: The Player record carries position x 1000 m, y 0 m, z 700 m, yVelocity 0 m/s, cameraYaw 0 rad, cameraPitch 0 rad, footstepTimer 0 s, health 100, maxHealth 100, stamina 100, maxStamina 100, magicka 100, maxMagicka 100, level 1, xp 0, xpToNext 100, gold 15, weaponDamage 8, arrowDamage 0, magicDamage 6, armor 0, speed 6 m/s, sprintSpeed 10 m/s, moveSpeed 6 m/s, jumpVelocity 5 m/s, attackCooldown 0 s, magicCooldown 0 s, bowCooldown 0 s, meleeRange 2.5 m, bowRange 30 m, magicRange 15 m, stealth 0, perception 5, crouched false, sprinting false, dead false, won false, completedSideQuests 0, inventory a list of Item ids starting with Iron Sword 1, Iron Arrow 10, and Health Potion 1, equippedWeaponId Iron Sword, equippedArmorId none, and selectedPotionId Health Potion.

WORLD: The World record carries seed 0, sizeX 2000 m, sizeY 1400 m, regionCount 6, gravity 9.8 m/s^2, waterLevel 0 m, timeOfDay 12 h, weather Clear, weatherTimer 120 s, playerStartX 1000 m, and playerStartZ 700 m.

REGION: The Region record carries id 1 to 6, name, biome, threat, radius, centerX 0 m, centerZ 0 m, enemyCount 0, npcCount 0, and respawnTimer 120 s. The fixed roster is Northreach snow threat 5 radius 220 m, Eldergrove forest threat 3 radius 200 m, Riverfall farmland threat 2 radius 180 m, Stonewatch rocky threat 4 radius 190 m, Ashenmoor swamp threat 3 radius 210 m, and Windhollow hills threat 2 radius 180 m.

ENEMY: The Enemy record carries id, type, name, position x 0 m, y 0 m, z 0 m, health, maxHealth, damage, speed, aggroRange, attackRange, attackCooldown, armor, xp, goldMin, goldMax, behavior, ranged, aggro false, dead false, outOfRangeTimer 0 s, and wanderTimer 0 s. The fixed roster is Wolf health 30 maxHealth 30 damage 6 speed 7 m/s aggroRange 12 m attackRange 2 m attackCooldown 1.0 s armor 0 xp 20 goldMin 0 goldMax 3 behavior ground ranged false, Bandit health 50 maxHealth 50 damage 10 speed 5 m/s aggroRange 15 m attackRange 2 m attackCooldown 1.2 s armor 2 xp 35 goldMin 5 goldMax 15 behavior ground ranged false, Skeleton health 40 maxHealth 40 damage 8 speed 4 m/s aggroRange 10 m attackRange 2 m attackCooldown 1.0 s armor 1 xp 25 goldMin 2 goldMax 8 behavior ground ranged false, Golem health 120 maxHealth 120 damage 18 speed 3 m/s aggroRange 10 m attackRange 3 m attackCooldown 2.0 s armor 6 xp 80 goldMin 10 goldMax 30 behavior ground ranged false, Draugr health 70 maxHealth 70 damage 12 speed 4 m/s aggroRange 14 m attackRange 2.5 m attackCooldown 1.1 s armor 3 xp 50 goldMin 10 goldMax 25 behavior ground ranged false, and Dragon health 500 maxHealth 500 damage 30 speed 8 m/s aggroRange 40 m attackRange 12 m attackCooldown 2.0 s armor 20 xp 500 goldMin 0 goldMax 0 behavior flying ranged true.

NPC: The NPC record carries id, type, name starts empty, position x 0 m, y 0 m, z 0 m, health 100, maxHealth 100, speed 3 m/s, questWeight 0, shopWeight 0, topic Greet, and dialogueOpen false. The fixed roster of types is Villager questWeight 0 shopWeight 0 topic Greet, Smith questWeight 0 shopWeight 5 topic Trade, Mage questWeight 3 shopWeight 2 topic Magic, QuestGiver questWeight 5 shopWeight 0 topic Quest, and Merchant questWeight 0 shopWeight 5 topic Trade.

ITEM: The Item record carries id, name, type, damage 0, armor 0, value 0, stack 1, and effect 0 points. The fixed roster is Iron Sword type weapon damage 8 value 10 stack 1, Steel Sword type weapon damage 12 value 35 stack 1, Iron Arrow type ammo damage 10 value 1 stack 20, Steel Arrow type ammo damage 14 value 3 stack 20, Health Potion type consumable effect health 40 points value 5 stack 10, Stamina Potion type consumable effect stamina 50 points value 5 stack 10, Magicka Potion type consumable effect magicka 50 points value 5 stack 10, Leather Armor type armor armor 3 value 15 stack 1, Iron Armor type armor armor 6 value 40 stack 1, and Dragon Scale type quest value 50 stack 1.

QUEST: The Quest record carries id, name, target, count, current 0, rewardXp, rewardGold, state Hidden, and giverNpcId 0. The fixed roster is Wolf Trouble target Wolf count 3 rewardXp 60 rewardGold 20, Bandit Purge target Bandit count 4 rewardXp 90 rewardGold 35, Skeleton Cleanse target Skeleton count 5 rewardXp 120 rewardGold 50, Golem Break target Golem count 1 rewardXp 200 rewardGold 100, and Dragon Hunt target Dragon count 1 rewardXp 500 rewardGold 200 state Locked.

SKILL: The Skill record carries id, name, level 1, xp 0, xpToNext 100, and bonus 1. The fixed roster is One-Handed, Archery, Destruction, Stealth, Speech, and Restoration, each with level 1, xp 0, xpToNext 100, and bonus 1.

LOOT: The Loot record carries itemId, quantity 1, position x 0 m, y 0 m, and z 0 m.

SYSTEMS: WORLD, SEEDED GENERATOR, PLAYER CONTROLS, COMBAT, ENEMY AI, STEALTH, LEVELING, INVENTORY, QUESTS, DIALOGUE, WEATHER.

WORLD: The land is rolling pine hills, rocky passes, snowy peaks, river valleys, farmland, and forest clearings, with stone ruins, wooden villages, watchtowers, and cave mouths standing on them. The world answers with its size and its regions. If Player position x is less than 0 m or greater than World sizeX, set Player position x to the nearest bound; if Player position z is less than 0 m or greater than World sizeY, set Player position z to the nearest bound. The world provides a terrain height at every x and z, and if Player y is less than terrain height, set Player y to terrain height. A position belongs to the Region whose center is nearest when distance is no more than that Region radius; if no Region contains the position, the region is neutral. If Player position is in water where terrain height is less than World waterLevel, set Player moveSpeed to 4 m/s.

SEEDED GENERATOR: The generator uses World seed 0 and re-rolls with the next seed if any verifier fails. It places the six Region centers by hashing the seed with each Region id, keeping centers at least 100 m from world edges and at least 250 m apart. It sets each Region enemyCount from threat: threat 1 is 3, threat 2 is 5, threat 3 is 7, threat 4 is 9, and threat 5 is 12. It chooses enemy types by biome: snow uses Wolf, Draugr, and Dragon; forest uses Wolf and Bandit; farmland uses Bandit and Wolf; rocky uses Skeleton and Golem; swamp uses Draugr and Skeleton; and hills uses Wolf and Bandit. It places one Dragon in Northreach and fills the remaining enemy slots with the chosen types at random positions inside the Region radius. It places two NPCs in each Region, one QuestGiver and one Merchant, sets Region npcCount to 2, and keeps NPC positions at least 20 m apart. It chooses three side quests from Wolf Trouble, Bandit Purge, Skeleton Cleanse, and Golem Break, assigns them to three different QuestGivers, and keeps Dragon Hunt assigned to the Northreach QuestGiver. It places one Loot pile in each Region at least 10 m from every NPC and at least 5 m from every other Loot pile, with one item from the Region biome loot: snow gives Iron Armor, forest gives Health Potion, farmland gives Steel Arrow, rocky gives Iron Sword, swamp gives Iron Armor, and hills gives Leather Armor. The verifier checks that no enemy is within 20 m of any NPC, no enemy is within 15 m of World playerStartX and playerStartZ, no two enemy positions are within 3 m, no two Loot piles are within 5 m, every Region has one QuestGiver and one Merchant, Northreach has one Dragon, total enemies are at least 20, each assigned quest target has at least its count enemies in the world, and all Region centers are at least 250 m apart; re-roll with the next seed if any fails.

PLAYER CONTROLS: W and Up move forward relative to Player cameraYaw, S and Down move backward, A and Left strafe left, D and Right strafe right, Shift sets Player sprinting true while held and false when released, Space jumps if Player yVelocity is 0, C sets Player crouched true while held and false when released, E interacts, F fires bow, Q drinks selected potion, mouse drag changes Player cameraYaw and cameraPitch with sensitivity 0.002 rad per px and max pitch 1.2 rad, left mouse attacks, right mouse casts magic, and Escape pauses. Touch uses the left half of the screen as a virtual joystick for movement, the right half as a drag pad for camera, a tap on the right edge as attack, a double tap on the right edge as bow, and a hold on the right edge as crouch. If Player sprinting is true and Player stamina is greater than 0, set Player moveSpeed to Player sprintSpeed and reduce Player stamina by 10 per s; if Player sprinting is true and Player stamina is 0, set Player moveSpeed to Player speed. If Player crouched is true, set Player moveSpeed to 4 m/s. If World weather is Rain or Snow, reduce Player moveSpeed by 1 m/s, but not below 2 m/s. If Player position is in water, set Player moveSpeed to 4 m/s. Every frame, reduce Player footstepTimer by frame time, not below 0. If Player sprinting is false, increase Player stamina by 15 per s up to Player maxStamina. If Space is pressed and Player yVelocity is 0, set Player yVelocity to Player jumpVelocity. Every frame, reduce Player yVelocity by World gravity times frame time and add it to Player y. If Player position changes at least 1 m since the last footstep, set Player footstepTimer to 0.4 s.

COMBAT: Every frame, reduce Player attackCooldown, magicCooldown, and bowCooldown by frame time, not below 0, increase Player health by 1 per s up to Player maxHealth, and increase Player magicka by 10 per s up to Player maxMagicka. Line of sight exists when the straight distance is no more than the stated range and the terrain height difference between the two positions is no more than 5 m. If Player dead is true, no player action has an effect. If left mouse or touch attack is pressed and Player attackCooldown is 0, set Player attackCooldown to 0.5 s, set Player crouched to false, set Player stealth to 0, and find the nearest Enemy whose distance is no more than Player meleeRange and whose facing angle from Player is no more than 30°; if one exists, calculate damage as the greater of 1 and Player weaponDamage minus Enemy armor; if the Enemy angle from Player is greater than 120°, add 5 to damage; if Player level is 5 or higher, add 2 to damage; set Enemy health to Enemy health minus damage; and add 10 xp to One-Handed. If right mouse is pressed and Player magicka is at least 6 and Player magicCooldown is 0, set Player magicCooldown to 1.0 s, reduce Player magicka by 6, set Player stealth to 0, find the nearest Enemy within Player magicRange with line of sight, set Enemy health to Enemy health minus Player magicDamage, and add 10 xp to Destruction; magic damage ignores Enemy armor. If F is pressed and Player bowCooldown is 0 and the Player inventory contains at least 1 Iron Arrow or Steel Arrow, consume 1 Iron Arrow if present, otherwise consume 1 Steel Arrow, set Player bowCooldown to 1.0 s, set Player stealth to 0, find the nearest Enemy within Player bowRange with line of sight, calculate damage as the greater of 1 and the arrow item damage plus Player arrowDamage minus Enemy armor, set Enemy health to Enemy health minus damage, and add 10 xp to Archery. If Q is pressed and the Player inventory contains at least 1 of selectedPotionId, consume 1 potion and add its effect to the matching Player health, stamina, or magicka, capping at the matching maximum. If Enemy is alive, Enemy aggro is true, Enemy attackCooldown is 0, and the distance from Enemy to Player is no more than Enemy attackRange, set Enemy attackCooldown to its own attackCooldown value and reduce Player health by the greater of 1 and Enemy damage minus Player armor; if the Enemy is a Dragon and the distance is no more than 12 m and the angle from the Dragon is no more than 45°, reduce Player health by 30 instead. If Player health is less than or equal to 0, set Player dead to true. If Enemy health is less than or equal to 0, set Enemy health to 0, set Enemy dead to true, add Enemy xp to Player xp, add a random integer between Enemy goldMin and Enemy goldMax to Player gold, and create one Loot pile at the Enemy position with one item chosen by type: Wolf drops Iron Arrow with 40%, Health Potion with 30%, and nothing with 30%; Bandit drops Steel Sword with 20%, Steel Arrow with 30%, and nothing with 50%; Skeleton drops Iron Armor with 25% and nothing with 75%; Golem drops Iron Armor with 50%, Dragon Scale with 10%, and nothing with 40%; Draugr drops Iron Armor with 40%, Dragon Scale with 10%, and nothing with 50%; and Dragon drops Dragon Scale with 100%.

ENEMY AI: If Enemy dead is true, no rule applies. If Player dead is true, set Enemy aggro to false. Every frame, reduce Enemy attackCooldown by frame time, not below 0. If the distance from Enemy to Player is no more than the effective aggroRange and line of sight exists, set Enemy aggro to true. The effective aggroRange is Enemy aggroRange when Player stealth is 33 or less, Enemy aggroRange minus 2 when Player stealth is 34 to 66, and Enemy aggroRange minus 5 when Player stealth is 67 to 100; if the result is less than 5, set it to 5. If Player stealth is 100 and Enemy aggro is false, the Enemy does not aggro from sight. If Enemy aggro is true and the distance is greater than Enemy attackRange, move Enemy toward Player at Enemy speed; if Enemy ranged is true, move only when distance is greater than Enemy attackRange; if distance is no more than Enemy attackRange, stop moving and let COMBAT handle the attack. If Enemy behavior is flying, keep Enemy y at 10 m above terrain height, move horizontally toward Player at Enemy speed, and if distance is greater than 12 m do not attack. If Enemy health is less than 25% of Enemy maxHealth, move at Enemy speed plus 2. If Enemy aggro is false, increase Enemy wanderTimer by frame time; when Enemy wanderTimer reaches 3 s, set Enemy wanderTimer to 0, choose a random direction, move at Enemy speed times 0.5 for 2 s, then stop for 1 s. If Enemy aggro is true and the distance is greater than Enemy aggroRange plus 10 m, increase Enemy outOfRangeTimer by frame time; otherwise set Enemy outOfRangeTimer to 0. If Enemy outOfRangeTimer reaches 10 s, set Enemy aggro to false. If Region respawnTimer is greater than 0, reduce it by frame time; when it reaches 0, respawn the Region enemyCount enemies at new random positions in that Region using the same type mix, reset Region respawnTimer to 120 s, and if the Region is Northreach include one Dragon. When any Enemy in a Region dies, set that Region respawnTimer to 120 s.

STEALTH: If Player crouched is true and Player sprinting is false, increase Player stealth by 10 per s up to 100; if Player crouched is false, reduce Player stealth by 20 per s down to 0; if Player sprinting is true, reduce Player stealth by 50 per s down to 0. If Player perception is greater than 5, increase the stealth gain by 1 per s for each point above 5, up to +5. If Player attacks, casts, or fires, set Player stealth to 0. If Player is in water, set Player stealth to 0.

LEVELING: When Player xp is at least Player xpToNext, increase Player level by 1, reduce Player xp by Player xpToNext, increase Player maxHealth by 5, increase Player health by 5, increase Player maxStamina by 2, increase Player stamina by 2, increase Player maxMagicka by 2, increase Player magicka by 2, and increase Player xpToNext by 50. When any Skill xp is at least that Skill xpToNext, increase Skill level by 1, reduce Skill xp by Skill xpToNext, increase Skill xpToNext by 50, and apply the Skill bonus: One-Handed adds 1 to Player weaponDamage, Archery adds 1 to Player arrowDamage, Destruction adds 1 to Player magicDamage, Stealth adds 1 to Player perception, Speech adds 5 to Player gold, and Restoration adds 2 to Player maxHealth and 2 to Player health. If Player level is 10 or higher, no further level up occurs, but Skill xp still levels.

INVENTORY: The Player inventory holds at most 30 slots, and items with stack 20 occupy one slot until full. If Player presses Tab, open the inventory screen; if the inventory screen is open, 1 through 9 select a slot, E equips the selected weapon or armor, Q selects the selected potion, and Escape closes it. If a weapon is equipped, set Player equippedWeaponId to that item and set Player weaponDamage to the item damage plus One-Handed level minus 1. If an armor is equipped, set Player equippedArmorId to that item and set Player armor to the item armor. If a potion is selected, set Player selectedPotionId to that item. If no dialogue is open and Player is within 2 m of a Loot pile and presses E, add the Loot itemId with quantity to the Player inventory, remove the Loot pile, and if the item is a weapon or armor equip it automatically. If the Player buys an item, remove its value from Player gold and add the item to inventory; if the Player sells an item, remove the item from inventory and add half its value to Player gold, rounded down.

QUESTS: If Player is within 3 m of a QuestGiver and presses E, open the quest topic. If a quest state is Hidden and the QuestGiver has that quest, set quest state to Active and set giverNpcId to that NPC. When an Enemy dies, if any Active quest has target equal to Enemy type, increase that quest current by 1. If quest current is at least quest count, set quest state to Complete, add quest rewardXp to Player xp, add quest rewardGold to Player gold, and if the quest is not Dragon Hunt increase Player completedSideQuests by 1. Dragon Hunt state is Locked until Player level is 5 or higher and Player completedSideQuests is 3 or higher; when those conditions are true, set Dragon Hunt state to Hidden and assign it to the Northreach QuestGiver. If Dragon Hunt is Complete, set Player won to true.

DIALOGUE: If Player presses E while within 3 m of an NPC, set NPC dialogueOpen to true and show topics based on NPC topic. If topic is Greet, show one line of greeting and close with E. If topic is Trade and NPC shopWeight is greater than 0, show a shop: Smith stock is Steel Sword 2, Steel Arrow 20, and Iron Armor 1; Merchant stock is Health Potion 5, Stamina Potion 5, Magicka Potion 5, and Leather Armor 1; Mage stock is Steel Sword 1, Magicka Potion 3, and Dragon Scale 1. Buying uses INVENTORY buy rules, and selling uses INVENTORY sell rules. If topic is Quest and NPC questWeight is greater than 0, show any Hidden quest assigned to that NPC and let Player accept it. If Speech level is greater than 1, reduce buy price by Speech level minus 1, but not below 1. If Player presses Escape or E, close dialogue and set NPC dialogueOpen to false.

WEATHER: Every 60 s, increase World timeOfDay by 1 h and wrap 24 h back to 0 h. Every frame, reduce World weatherTimer by frame time; when it reaches 0, set World weatherTimer to 120 s and choose World weather from Clear with 50, Rain with 30, and Snow with 20, or if the Player is in a snow Region choose Snow with 50, Rain with 30, and Clear with 20. If World weather is Rain, ENEMY AI uses Enemy aggroRange minus 2 and Player moveSpeed is reduced by 1 m/s. If World weather is Snow, ENEMY AI moves each Enemy at Enemy speed minus 1 and Player moveSpeed is reduced by 1 m/s. If World timeOfDay is less than 6 h or at least 20 h, ENEMY AI uses Enemy aggroRange plus 2.

CORE LOOP: The player explores the generated land through WORLD and SEEDED GENERATOR, finds NPCs and enemies, accepts quests in DIALOGUE, fights with COMBAT and ENEMY AI, uses STEALTH to avoid or ambush, picks up Loot and trades in INVENTORY, gains xp and skill levels in LEVELING, and returns to quest givers to complete QUESTS. Each loop grows Player level, skill levels, gold, and equipment, unlocks better items and the final Dragon Hunt, and the win is setting Player won true by completing Dragon Hunt.

SCREENS: title (shows the game title, a press Enter or tap to begin, and a short control list) → game (shows the 3D world, HUD, and overlays) → win (shows the dragon slain and offers continue exploring, which returns to game, or restart with R or tap) → pause (shows resume, restart, and controls, and stops all systems) → game over (shows that the player is dead and offers restart with R or tap). During game, E near an NPC opens dialogue, Tab opens inventory, and Escape opens pause or closes an open overlay. The HUD shows Player health, maxHealth, stamina, maxStamina, magicka, maxMagicka, level, xp, xpToNext, gold, the latest Active quest name and current/count from Quest, Region name from the current Region, World timeOfDay, and World weather.

AUDIO: All audio is generated with the Web Audio API. Play a footstep when Player footstepTimer reaches 0. Play a sword swing when left mouse or touch attack is pressed. Play a hit when any Enemy health is reduced. Play a magic zap when right mouse is pressed and magicka is at least 6. Play a bow twang when F is pressed and an arrow is consumed. Play a potion gulp when Q consumes a potion. Play an enemy death when Enemy health reaches 0. Play a quest complete when a Quest state changes to Complete. Play a level up when Player level increases. Play a dialogue chime when NPC dialogueOpen becomes true. Play a low wind loop during Clear, a rain loop during Rain, and a soft snow loop during Snow, with the loop changing when World weather changes.

ART: ask for a player knight as a sprite, ask for a wolf as a sprite, ask for a bandit as a sprite, ask for a skeleton as a sprite, ask for a golem as a sprite, ask for a draugr as a sprite, ask for a dragon as a sprite, ask for a villager as a sprite, ask for a smith as a sprite, ask for a mage as a sprite, ask for a quest giver as a sprite, ask for a merchant as a sprite, ask for an iron sword icon as a sprite, ask for a steel sword icon as a sprite, ask for an iron arrow icon as a sprite, ask for a steel arrow icon as a sprite, ask for a health potion icon as a sprite, ask for a stamina potion icon as a sprite, ask for a magicka potion icon as a sprite, ask for a leather armor icon as a sprite, ask for an iron armor icon as a sprite, ask for a dragon scale icon as a sprite, ask for a snowy peak biome tile as a tile, ask for a forest biome tile as a tile, ask for a farmland biome tile as a tile, ask for a rocky biome tile as a tile, ask for a swamp biome tile as a tile, and ask for a hills biome tile as a tile. Everything else — terrain geometry, water, fog, lighting, UI, particles, shadows, projectiles, hit effects, and quest markers — is drawn in code.
