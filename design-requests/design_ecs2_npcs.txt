Build this village mystery where you talk to villagers to find who stole the silver bell. Every number below is a given value to write into the code as-is; none of them needs checking or deriving.

RECORDS: GAME, PLAYER, VILLAGER, LOCATION, CLUE, STOLEN ITEM, DIALOGUE, ACCUSATION.

GAME: seed 1 to 999999, currentDay 1, maxDays 3, dayPhase 0, phasesPerDay 4, actionsLeft 4, maxActionsPerDay 4, thiefId 0, gameOver 0, win 0, accusedId 0, totalClueCount 8, clueFoundCount 0.

PLAYER: id 1, locationId 1, reputation 50, maxReputation 100, accusationsLeft 3, maxAccusations 3, clueCount 0, maxClueCount 8, speed 140 px/s, moveCooldown 400 ms.

VILLAGER: id 1 to 10, role from the roster Farmer, Baker, Blacksmith, Innkeeper, Fisher, Priest, Child, Elder, Miller, Hunter, name generated, morningLocationId 0, afternoonLocationId 0, eveningLocationId 0, nightLocationId 0, alibiText generated, secretText generated, guilt 0, suspicion 0, maxSuspicion 100, hostility 0, maxHostility 100, talkedTo 0, liesLeft 3, maxLies 3, secretRevealed 0, alibiBroken 0, cooperative 0, clueIds empty, clueCount 0; role values Farmer baseHostility 10, baseLies 3, baseCooperative 0, Baker 10, 3, 0, Blacksmith 20, 2, 0, Innkeeper 5, 4, 1, Fisher 10, 3, 0, Priest 15, 3, 0, Child 0, 1, 1, Elder 20, 2, 0, Miller 10, 3, 0, Hunter 15, 2, 0.

LOCATION: id 1 to 9, name from the roster Square, Church, Mill, Bakery, Inn, Docks, Smithy, Forest, Graveyard, clueCapacity 2, visitCost 1, maxVillagers 3, connectedIds empty, currentVillagerIds empty, clueIds empty; roster values Square clueCapacity 2, visitCost 0, maxVillagers 4, Church 2, 1, 3, Mill 1, 1, 2, Bakery 2, 1, 3, Inn 2, 1, 4, Docks 1, 1, 2, Smithy 1, 1, 2, Forest 2, 1, 3, Graveyard 1, 1, 2.

CLUE: id 1 to 12, name from the roster broken latch, muddy boots, missing key, overheard threat, forged note, cut bell rope, fish market debt, church donation list, inn tab, graveyard visit, mill shortcut, hunter's knife, type physical, statement, motive, opportunity, weight, sourceVillagerId 0, targetVillagerId 0, locationId 0, found 0, revealed 0, contradicted 0; roster values broken latch physical 10, muddy boots physical 15, missing key physical 20, overheard threat statement 25, forged note statement 30, cut bell rope physical 20, fish market debt motive 15, church donation list motive 20, inn tab motive 15, graveyard visit opportunity 20, mill shortcut opportunity 25, hunter's knife physical 30.

STOLEN ITEM: id 1, name silver bell, weight 20, clueWeight 25, hideLocationId 0, found 0, describedBy 0.

DIALOGUE: activeVillagerId 0, targetVillagerId 0, topicId 0, optionIndex 0, pendingClueId 0, pendingSuspicion 0, pendingHostility 0, pendingReputation 0, resolved 0, maxOptions 4.

ACCUSATION: targetId 0, evidenceScore 0, success 0, penalty 0, maxEvidence 100.

SYSTEMS: SEEDED GENERATOR, DAY AND TIME, MOVEMENT, DIALOGUE AND INTERROGATION, EVIDENCE AND SUSPICION, VILLAGER REACTIONS, ACCUSATION AND RESOLUTION.

SEEDED GENERATOR: when a new game starts, the generator takes GAME.seed and chooses GAME.thiefId from 1 to 10, sets the matching Villager.guilt to 1 and every other Villager.guilt to 0, assigns each Villager.role from the role roster without repeats, assigns each Villager.morningLocationId, afternoonLocationId, eveningLocationId, and nightLocationId from LOCATION ids so that no LOCATION exceeds LOCATION.maxVillagers in any dayPhase, chooses GAME.totalClueCount 8 clue ids from the CLUE roster without repeats, sets each chosen CLUE.locationId to a LOCATION with remaining clueCapacity, sets CLUE.sourceVillagerId and CLUE.targetVillagerId so that at least 4 clues have targetVillagerId equal to GAME.thiefId, at least 2 clues have targetVillagerId equal to an innocent Villager, at least 1 clue has sourceVillagerId equal to an innocent Villager, and no clue has both sourceVillagerId and targetVillagerId equal to 0, sets each Villager.clueIds to the ids of clues whose targetVillagerId equals that Villager.id and sets that Villager.clueCount to the number of those clues, sets STOLEN ITEM.hideLocationId to the thief's nightLocationId, generates each Villager.alibiText and secretText from role and seed so that the thief's alibiText is false and its secretText names the hiding place while each innocent Villager's alibiText is true and its secretText names a minor fault, sets each Villager.hostility to its role baseHostility, each Villager.liesLeft to its role baseLies, and each Villager.cooperative to its role baseCooperative, connects every LOCATION to 2 or 3 other LOCATION ids in connectedIds with no self-link and no duplicate link so that every LOCATION is reachable from Square in 3 or fewer links, and sets LOCATION.currentVillagerIds and LOCATION.clueIds for the initial dayPhase; the VERIFIER checks that a thief exists, every Villager has a unique role, every Villager has valid location assignments for all four dayPhase values, every chosen clue has a valid location and target, at least 4 clues point to GAME.thiefId, at least 2 clues point to an innocent, STOLEN ITEM.hideLocationId is a valid LOCATION, every LOCATION is reachable from Square, no LOCATION exceeds maxVillagers in any phase, and GAME.totalClueCount is 8, and re-roll with the next seed if any fails.

DAY AND TIME: when GAME.actionsLeft becomes 0, set GAME.dayPhase to GAME.dayPhase + 1 and set GAME.actionsLeft to GAME.maxActionsPerDay; if GAME.dayPhase becomes greater than GAME.phasesPerDay - 1, set GAME.dayPhase to 0, set GAME.currentDay to GAME.currentDay + 1, and if GAME.currentDay becomes greater than GAME.maxDays, set GAME.gameOver to 1 and GAME.win to 0; at the start of each new day, reduce each Villager with guilt 1 and liesLeft greater than 0 by 1 in liesLeft, and set LOCATION.currentVillagerIds for the new dayPhase from each Villager's location fields.

MOVEMENT: A Villager's current location is its morningLocationId when GAME.dayPhase is 0, its afternoonLocationId when GAME.dayPhase is 1, its eveningLocationId when GAME.dayPhase is 2, and its nightLocationId when GAME.dayPhase is 3; when the player presses A, D, W, S or the left, right, up, or down arrow, the game highlights the connected LOCATION closest to that screen direction and if none exists cycles to the next connected LOCATION; when the player presses Enter or taps the highlighted LOCATION, the game closes any open DIALOGUE by setting DIALOGUE.activeVillagerId to 0 and DIALOGUE.resolved to 1, and if the destination LOCATION.visitCost is 0 it moves without changing GAME.actionsLeft, while if LOCATION.visitCost is 1 it requires GAME.actionsLeft to be greater than 0, sets GAME.actionsLeft to GAME.actionsLeft - 1, and begins a move animation of PLAYER.speed 140 px/s and PLAYER.moveCooldown 400 ms; when the move finishes, set PLAYER.locationId to the destination LOCATION; when the player presses Q or taps search, the game requires GAME.actionsLeft to be greater than 0, sets GAME.actionsLeft to GAME.actionsLeft - 1, and if the current LOCATION contains an unfound CLUE sets the first such CLUE.found to 1; when the player presses E or taps a villager card, the game lists every Villager whose current location equals PLAYER.locationId, and when the player presses Enter on a listed Villager or taps that card, set DIALOGUE.activeVillagerId to that Villager.id, set DIALOGUE.targetVillagerId to 0, set DIALOGUE.topicId to 1, set DIALOGUE.optionIndex to 0, set DIALOGUE.pendingClueId to 0, set DIALOGUE.pendingSuspicion to 0, set DIALOGUE.pendingHostility to 0, set DIALOGUE.pendingReputation to 0, and set DIALOGUE.resolved to 0; when the player presses Escape, close DIALOGUE by setting DIALOGUE.activeVillagerId to 0 and DIALOGUE.resolved to 1.

DIALOGUE AND INTERROGATION: when DIALOGUE.activeVillagerId changes from 0 to a Villager.id, set that Villager.talkedTo to 1; when the player presses 1, 2, 3, or 4 or taps a topic button, set DIALOGUE.topicId to that number and set DIALOGUE.optionIndex to that number; topic 1 is Ask alibi, topic 2 is Ask about bell, topic 3 is Ask about target, and topic 4 is Press with clue; when the player taps a found CLUE in the dialogue clue list, set DIALOGUE.pendingClueId to that CLUE.id; when topic 1 is selected, if the active Villager.guilt is 1 set DIALOGUE.pendingReputation to -5 if that Villager.hostility is greater than 20 else 0, and if any found CLUE has sourceVillagerId equal to the active Villager.id and type statement, set DIALOGUE.pendingClueId to that CLUE.id, while if the active Villager.guilt is 0 set DIALOGUE.pendingReputation to 5; when topic 2 is selected, if the active Villager.cooperative is 1 or PLAYER.reputation is at least 70 set DIALOGUE.pendingReputation to 5 and if any unfound CLUE has sourceVillagerId equal to the active Villager.id set DIALOGUE.pendingClueId to that CLUE.id, otherwise set DIALOGUE.pendingHostility to 10 and DIALOGUE.pendingReputation to -5; when topic 3 is selected, if DIALOGUE.targetVillagerId is 0 no clue is found, but if DIALOGUE.targetVillagerId is greater than 0 and any CLUE has sourceVillagerId equal to the active Villager.id and targetVillagerId equal to DIALOGUE.targetVillagerId, set DIALOGUE.pendingClueId to that CLUE.id, and if the active Villager.cooperative is 0 and active Villager.hostility is greater than 30 set DIALOGUE.pendingHostility to 10 and DIALOGUE.pendingReputation to -5, otherwise set DIALOGUE.pendingReputation to 5; when topic 4 is selected, if DIALOGUE.pendingClueId is 0 no effect occurs, but if DIALOGUE.pendingClueId is greater than 0 set DIALOGUE.pendingSuspicion to that CLUE.weight, set DIALOGUE.pendingHostility to 10 if DIALOGUE.targetVillagerId equals DIALOGUE.activeVillagerId else 5, and set DIALOGUE.pendingReputation to 5 if that CLUE.type is physical else 10; when the player presses Enter to confirm a topic, the game requires GAME.actionsLeft to be greater than 0, sets GAME.actionsLeft to GAME.actionsLeft - 1, changes DIALOGUE.targetVillagerId's Villager.suspicion by DIALOGUE.pendingSuspicion capped at that Villager.maxSuspicion if DIALOGUE.targetVillagerId is greater than 0, changes the active Villager.hostility by DIALOGUE.pendingHostility capped at that Villager.maxHostility, changes PLAYER.reputation by DIALOGUE.pendingReputation capped at PLAYER.maxReputation and not below 0, and if DIALOGUE.pendingClueId is greater than 0 sets that CLUE.found to 1, sets that CLUE.revealed to 1, and sets the active Villager.secretRevealed to 1; if DIALOGUE.pendingSuspicion is at least 20 and DIALOGUE.targetVillagerId equals DIALOGUE.activeVillagerId, set that Villager.alibiBroken to 1; if the active Villager.guilt is 1 and DIALOGUE.pendingSuspicion is at least 20, reduce the active Villager.liesLeft by 1 not below 0 and set that Villager.alibiBroken to 1; if GAME.actionsLeft is 0 after the action, set DIALOGUE.resolved to 1 and close DIALOGUE.

EVIDENCE AND SUSPICION: when CLUE.found changes from 0 to 1, set PLAYER.clueCount to PLAYER.clueCount + 1, set GAME.clueFoundCount to GAME.clueFoundCount + 1, and if CLUE.targetVillagerId is greater than 0 raise that Villager.suspicion by CLUE.weight capped at that Villager.maxSuspicion; when a found CLUE has type statement and its targetVillagerId has guilt 1, set that Villager.alibiBroken to 1; when two found CLUEs of different types point to the same targetVillagerId, raise that Villager.suspicion by 10 capped at that Villager.maxSuspicion; when Villager.alibiBroken changes from 0 to 1 and that Villager.guilt is 1, raise that Villager.suspicion by 15 capped at that Villager.maxSuspicion; when Villager.suspicion changes from below 80 to 80 or more, raise that Villager.hostility by 20 capped at that Villager.maxHostility; when PLAYER.reputation changes from below 70 to 70 or more, set every Villager.cooperative to 1; when STOLEN ITEM.found changes from 0 to 1, set STOLEN ITEM.describedBy to 1 and reduce every Villager with guilt 0 by 10 in suspicion, not below 0.

VILLAGER REACTIONS: at the start of each GAME.dayPhase, for each Villager with guilt 1 and liesLeft greater than 0, if any found statement CLUE has targetVillagerId equal to that Villager.id, set one found statement CLUE.contradicted to 1, raise that Villager.hostility by 5 capped at that Villager.maxHostility, and set that Villager.alibiText to a new false statement generated from role and seed; when a Villager with guilt 1 has liesLeft change from 1 to 0, set that Villager.alibiBroken to 1 and raise that Villager.suspicion by 10 capped at that Villager.maxSuspicion; at the start of each GAME.dayPhase, for each Villager with suspicion greater than 60, set the location field matching the new dayPhase to a different LOCATION with available room if one exists, and if none exists raise that Villager.hostility by 5 capped at that Villager.maxHostility; when DIALOGUE.activeVillagerId is a Villager with cooperative 0 and hostility greater than 40, the first topic of that conversation automatically adds 5 to DIALOGUE.pendingHostility and -5 to DIALOGUE.pendingReputation; when GAME.dayPhase is 3 and STOLEN ITEM.found is 0, the guilty Villager moves to STOLEN ITEM.hideLocationId if that LOCATION has room, and when a search is used in STOLEN ITEM.hideLocationId with GAME.clueFoundCount at least 6, set STOLEN ITEM.found to 1.

ACCUSATION AND RESOLUTION: when the player presses X or taps Accuse in the accusation screen, the game requires PLAYER.accusationsLeft to be greater than 0 and a selected target, sets ACCUSATION.targetId to that target, sets PLAYER.accusationsLeft to PLAYER.accusationsLeft - 1, and sets ACCUSATION.evidenceScore to the sum of the weight of every found CLUE whose targetVillagerId equals ACCUSATION.targetId, plus 20 if that Villager.alibiBroken is 1, plus STOLEN ITEM.weight if STOLEN ITEM.found is 1 and that Villager.nightLocationId equals STOLEN ITEM.hideLocationId, plus STOLEN ITEM.clueWeight if STOLEN ITEM.found is 1, that Villager.nightLocationId equals STOLEN ITEM.hideLocationId, and that Villager.alibiBroken is 1, capped at ACCUSATION.maxEvidence; if ACCUSATION.targetId equals GAME.thiefId and ACCUSATION.evidenceScore is at least 60, set ACCUSATION.success to 1, GAME.win to 1, GAME.gameOver to 1, and GAME.accusedId to ACCUSATION.targetId; if ACCUSATION.targetId equals GAME.thiefId and ACCUSATION.evidenceScore is less than 60, set ACCUSATION.success to 0, ACCUSATION.penalty to 25, GAME.gameOver to 1, GAME.win to 0, GAME.accusedId to ACCUSATION.targetId, and reduce PLAYER.reputation by 25 not below 0; if ACCUSATION.targetId is not GAME.thiefId, set ACCUSATION.success to 0, ACCUSATION.penalty to 20, reduce PLAYER.reputation by 20 not below 0, reduce that Villager.suspicion by 20 not below 0, set GAME.accusedId to ACCUSATION.targetId, and if PLAYER.accusationsLeft is 0 set GAME.gameOver to 1 and GAME.win to 0, otherwise set GAME.gameOver to 0; when GAME.currentDay is greater than GAME.maxDays, set GAME.gameOver to 1 and GAME.win to 0.

CORE LOOP: The player starts from SEEDED GENERATOR, then repeats a minute to minute cycle through DAY AND TIME, MOVEMENT, DIALOGUE AND INTERROGATION, EVIDENCE AND SUSPICION, VILLAGER REACTIONS, and ACCUSATION AND RESOLUTION: spend actions moving and searching, talk to villagers to find clues, press suspects to raise suspicion, let reputation unlock cooperative answers, watch the thief lie or move, and accuse when evidence is strong; each successful conversation grows reputation, each clue grows suspicion and evidence, the win is accusing the thief with at least 60 evidence before day 3 ends or accusations run out, and a new seed offers a different thief, layout, and clue set.

SCREENS: title (shows the stolen item and a Start button) → game (shows the map, villager cards, clue list, day and actions) → dialogue (shows speaker portrait, topic buttons, clue result) → accusation (shows target portrait, evidence score, and an Accuse button) → game over (shows the thief if GAME.win is 1 or the failed case if GAME.win is 0 and offers Play Again). On title, Enter or Start runs SEEDED GENERATOR with a new seed and leads to game; Escape on title does nothing. In game, Escape opens a pause menu with Resume, Restart, and Title; Resume returns to game, Restart re-runs SEEDED GENERATOR with the same seed and leads to game, and Title returns to title. In dialogue, Escape returns to game. In accusation, Escape returns to game. On game over, Enter or Play Again runs SEEDED GENERATOR with a new seed and leads to game; Escape returns to title. The HUD reads GAME.currentDay, GAME.maxDays, GAME.dayPhase, GAME.actionsLeft, GAME.maxActionsPerDay, PLAYER.reputation, PLAYER.clueCount, PLAYER.accusationsLeft, and each Villager.suspicion when a villager card is visible.

AUDIO: generated with the Web Audio API, click plays when any button is pressed, move plays when PLAYER.locationId changes, dialogue plays when DIALOGUE.activeVillagerId changes from 0 to a Villager.id, clue plays when CLUE.found changes from 0 to 1, suspicion plays when a Villager.suspicion increases by 10 or more, accuse plays when ACCUSATION.targetId changes from 0 to a Villager.id, win plays when GAME.win changes from 0 to 1, lose plays when GAME.gameOver changes from 0 to 1 and GAME.win is 0, and day plays when GAME.dayPhase changes.
