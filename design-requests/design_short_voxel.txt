Build this voxel survival sandbox where the player mines blocks, builds a base, crafts tools, survives night mobs, and wins by placing a beacon. It is made of these systems. Every number below is a given value to write into the code as-is; none of them needs checking or deriving.

SYSTEMS: WORLD, PLAYER, BLOCKS, ITEMS, INVENTORY, CRAFTING, MINING, BUILDING, DAY_NIGHT, MOB_SPAWNING, MOB_AI, COMBAT, HEALTH_HUNGER, QUEST, UI, SCREENS, AUDIO, ART.

WORLD: The World record is the single source of truth for terrain and has fields seed, sizeX 64, sizeY 32, sizeZ 64, tiles, spawnX, spawnY, spawnZ, padX, padY, padZ. Each Tile in tiles is a record with fields x, y, z, blockId. The seeded generator uses the seed and the size values to fill the world in this order: fill every tile with air, generate a height value from 10 to 18 for every x and z, place grass at the height, place three dirt below it, place stone below the dirt, carve 40 cave chambers of radius 2 to 4, place 20 lakes of water at y 8, place 200 trees with a trunk of four wood and a leaves cap 5 wide and 3 high, place 120 coal ore, 80 iron ore, and 50 gold ore inside stone, and place a 3 by 3 stone beacon pad at padX, padY 20, padZ with air above. The verifier checks that spawn has three air tiles above it, spawn is not in water, the pad is not in water, no two trees share a trunk tile, no ore occupies water, there are at least 200 trees, at least 120 coal ore, at least 80 iron ore, and at least 50 gold ore, and a flood fill from spawn over air and solid tiles reaches the pad within 5000 tiles; re-roll with the next seed if any fails.

PLAYER: The Player record is the single source of truth for the player and has fields x, y, z, vx, vy, vz, yaw, pitch, health 20, hunger 20, onGround, inWater, attackCooldown 0. The Player record is read by UI, HEALTH_HUNGER, COMBAT, MINING, BUILDING, and MOB_AI. Controls: W and ArrowUp move forward, S and ArrowDown move back, A and ArrowLeft strafe left, D and ArrowRight strafe right, Space jumps, mouse drag looks, left click mines or attacks, right click places, mouse wheel or keys 1 through 9 select hotbar slots, E opens inventory, F eats the selected food, and Escape pauses. Touch controls: a 120 by 120 virtual joystick at the bottom left moves, dragging the right side looks, a 60 by 60 jump button at the bottom right jumps, a 60 by 60 mine button mines or attacks, a 60 by 60 place button places, a 40 by 40 eat button eats, and a 40 by 40 inventory button opens inventory. The player is 0.6 wide and 1.8 tall, moves at 4 blocks per second on land and 1.5 blocks per second in water, has gravity 20 on land and 2 in water, jump velocity 8 on land and 3 in water, and collides with solid blocks.

BLOCKS: The BlockType record is the single source of truth for block behavior and has fields id, name, hardness, dropId, dropCount, bonusId, bonusChance, solid, placeable, light. The roster is: air id 0 hardness 0 drop 0 count 0 solid false placeable false light 0; grass id 1 hardness 1 drop 1 count 1 solid true placeable true light 0; dirt id 2 hardness 1 drop 1 count 1 solid true placeable true light 0; stone id 3 hardness 3 drop 2 count 1 solid true placeable true light 0; wood id 4 hardness 2 drop 3 count 1 solid true placeable true light 0; planks id 5 hardness 1.5 drop 4 count 1 solid true placeable true light 0; leaves id 6 hardness 0.5 drop 5 count 1 bonus 20 chance 10 solid true placeable true light 0; sand id 7 hardness 1 drop 6 count 1 solid true placeable true light 0; water id 8 hardness 0 drop 0 count 0 solid false placeable false light 0; coal ore id 9 hardness 4 drop 7 count 1 solid true placeable false light 0; iron ore id 10 hardness 5 drop 8 count 1 solid true placeable false light 0; gold ore id 11 hardness 6 drop 9 count 1 solid true placeable false light 0; torch id 12 hardness 0.2 drop 17 count 1 solid false placeable true light 14; beacon id 13 hardness 5 drop 18 count 1 solid true placeable true light 15.

ITEMS: The Item record is the single source of truth for item behavior and has fields id, name, stackMax, type, blockId, miningClass, damage, hunger, heal, price. The roster is: none 0 stack 1 blockId 0 miningClass none type special price 0; dirt 1 stack 64 blockId 2 price 1; stone 2 stack 64 blockId 3 price 2; wood 3 stack 64 blockId 4 price 2; planks 4 stack 64 blockId 5 price 2; leaves 5 stack 64 blockId 6 price 1; sand 6 stack 64 blockId 7 price 1; coal 7 stack 64 blockId 0 price 5; iron 8 stack 64 blockId 0 price 10; gold 9 stack 64 blockId 0 price 20; stick 10 stack 64 blockId 0 price 1; wooden pickaxe 11 stack 1 blockId 0 miningClass wood price 15; stone pickaxe 12 stack 1 blockId 0 miningClass stone price 25; iron pickaxe 13 stack 1 blockId 0 miningClass iron price 40; wooden sword 14 stack 1 blockId 0 damage 3 price 15; stone sword 15 stack 1 blockId 0 damage 4 price 25; iron sword 16 stack 1 blockId 0 damage 6 price 40; torch 17 stack 64 blockId 12 price 3; beacon 18 stack 1 blockId 13 price 100; rotten flesh 19 stack 64 blockId 0 hunger 3 heal 1 price 1; apple 20 stack 64 blockId 0 hunger 4 heal 2 price 4. The type field is block, tool, weapon, food, or special, and the miningClass field is none, wood, stone, or iron. All items without a listed blockId have blockId 0, and all items without a listed miningClass have miningClass none.

INVENTORY: The Inventory record is the single source of truth for carried items and has fields slots and selectedSlot 0. Slots is a list of 36 ItemStack records, and each ItemStack has fields itemId 0 and count 0. Slots 0 through 8 are the hotbar and slots 9 through 35 are the backpack. INVENTORY is read by UI, CRAFTING, MINING, BUILDING, HEALTH_HUNGER, and COMBAT. When an item is added, it fills an existing stack of the same itemId up to its stackMax, then fills empty slots, and if no space remains it becomes a DroppedItem record. The selected slot is changed by keys 1 through 9, the mouse wheel, or touching a hotbar slot.

CRAFTING: The Recipe record is the single source of truth for crafting and has fields id, outputId, outputCount, ingredients. Each ingredient is a record with fields itemId and count. The roster is: recipe 1 outputId 4 outputCount 4 ingredients itemId 3 count 1; recipe 2 outputId 10 outputCount 4 ingredients itemId 4 count 2; recipe 3 outputId 11 outputCount 1 ingredients itemId 4 count 3 and itemId 10 count 2; recipe 4 outputId 12 outputCount 1 ingredients itemId 2 count 3 and itemId 10 count 2; recipe 5 outputId 13 outputCount 1 ingredients itemId 8 count 3 and itemId 10 count 2; recipe 6 outputId 14 outputCount 1 ingredients itemId 4 count 2 and itemId 10 count 1; recipe 7 outputId 15 outputCount 1 ingredients itemId 2 count 2 and itemId 10 count 1; recipe 8 outputId 16 outputCount 1 ingredients itemId 8 count 2 and itemId 10 count 1; recipe 9 outputId 17 outputCount 4 ingredients itemId 7 count 1 and itemId 10 count 1; recipe 10 outputId 18 outputCount 1 ingredients itemId 9 count 10, itemId 8 count 5, itemId 7 count 5, and itemId 4 count 4. A CraftAction record has fields recipeId and success. When success is true, CRAFTING removes the ingredients from INVENTORY, adds the output to INVENTORY, plays the craft sound, and tells QUEST to update pickaxe or beacon progress.

MINING: The MiningAction record has fields targetX, targetY, targetZ, progress 0, selectedItemId 0. The DroppedItem record is the single source of truth for dropped items and has fields x, y, z, itemId, count, age 0. The source of truth for the block being broken is the Tile in World.tiles, and MINING reads Player, Inventory, and BLOCKS. Left click or the touch mine button starts or continues mining a block within 5 blocks of the player. The block breaks when progress reaches 100 after the listed seconds have elapsed while the player keeps aiming at the block: hand, grass 1, dirt 1, sand 1, wood 2, planks 1.5, leaves 0.5, stone 3, coal ore 4, iron ore 5, gold ore 6, torch 0.2, beacon 5; wooden pickaxe, stone 2, coal ore 3, iron ore 4, gold ore 5, and all other blocks use the hand time; stone pickaxe, stone 1, coal ore 2, iron ore 3, gold ore 4, and all other blocks use the hand time; iron pickaxe, stone 0.5, coal ore 1, iron ore 2, gold ore 3, and all other blocks use the hand time. When a block breaks, its dropId and dropCount are added to INVENTORY, its bonusId is added if a roll from 1 to 100 is 1 through bonusChance, and if there is no space a DroppedItem appears at the block position. A DroppedItem is picked up when the player is within 1 block, disappears after 60 seconds, and if more than 20 DroppedItems exist the oldest one disappears.

BUILDING: The BuildAction record has fields targetX, targetY, targetZ, success false. The source of truth for the block to place is the Tile in World.tiles, and BUILDING reads Player, Inventory, and BLOCKS. Right click or the touch place button places the item in Inventory.selectedSlot into an air tile within 5 blocks, adjacent to at least one solid block, not overlapping the player or a mob, and not in water. It consumes 1 item, sets the tile to the Item.blockId, adds the Item.price to QUEST.blockValuePlaced, and if the item is torch it adds 1 to QUEST.torchesPlaced. If the placed block is beacon and the tile is the World pad, QUEST.beaconPlaced becomes true. A place fails if the tile is not air, the Item.blockId is 0, the item count is 0, or the placement would overlap a solid block, the player, or a mob.

DAY_NIGHT: The DayNight record is the single source of truth for time and has fields time 0 and length 240. Each second time increases by 1, and when time reaches 240 it becomes 0. Day is true when time is 0 through 179 and night is true when time is 180 through 239. DAY_NIGHT is read by UI, MOB_SPAWNING, MOB_AI, and QUEST. At time 0 the day sound plays, and at time 180 the night sound plays.

MOB_SPAWNING: The Mob record is the single source of truth for each mob and has fields id, type, x, y, z, health, maxHealth, damage, speed, state, attackTimer 0. MOB_SPAWNING creates Mob records and is read by MOB_AI, COMBAT, and UI. During night, every 5 seconds, if fewer than 8 mobs exist, the spawner tries to create up to 3 mobs. A spawn tile must be solid ground, have air above, not be water, be at least 16 blocks from the player, be at least 8 blocks from every torch, and be within the world. The type is chosen with 60 percent zombie, 30 percent skeleton, and 10 percent spider. The zombie has health 20, damage 3, speed 2.2, and drops itemId 19 count 1. The skeleton has health 15, damage 2, speed 2.6, and drops itemId 0 count 0. The spider has health 12, damage 2, speed 3.0, and drops itemId 0 count 0.

MOB_AI: MOB_AI updates each Mob record and reads Player, World.tiles, and DayNight. Each mob has state idle, chase, attack, or wander. If the straight-line distance to the player is 12 or less, state is chase and the mob moves toward the player at its speed. If the straight-line distance is 2 or less, state is attack and the mob deals its damage to the player every 1 second. If the straight-line distance is 24 or more, state is wander and the mob moves to a random adjacent air tile every 2 seconds. A zombie loses 5 health per second during day. When health reaches 0, the mob dies, drops its drop item, and is removed. Mobs collide with solid blocks and do not enter water.

COMBAT: The CombatAction record has fields source, target, damage 0, success false. COMBAT reads Player, Inventory, and Mob records. A player left click or touch mine button that hits a mob within 4 blocks with no solid block between deals 1 damage if the selected item is not a sword, or the sword damage value from ITEMS if it is a sword. The player attack cooldown is 0.4 seconds. A mob attack deals its damage value to Player.health and gives the player 2 blocks of knockback. A player hit plays the player hurt sound, a mob hit plays the mob hurt sound, and a mob death plays the mob death sound. When Player.health reaches 0, the game goes to game over.

HEALTH_HUNGER: HEALTH_HUNGER updates Player.health and Player.hunger. Every 30 seconds, hunger decreases by 1. If hunger is 0, health decreases by 1 every 5 seconds. If hunger is 18 or more and health is less than 20, health increases by 1 every 4 seconds. Pressing F or the touch eat button consumes 1 of the selected food item, adds its hunger value to hunger, adds its heal value to health, and caps both at 20. If health reaches 0, the player dies and the game goes to game over. If hunger reaches 20, it stays 20.

QUEST: The Quest record is the single source of truth for progression and has fields stage 0, woodCollected 0, pickaxeCrafted false, stoneMined 0, blockValuePlaced 0, torchesPlaced 0, nightsSurvived 0, goldCollected 0, beaconCrafted false, beaconPlaced false. The stages are: stage 1 collect 10 wood, stage 2 craft a pickaxe, stage 3 mine 10 stone, stage 4 place 50 value of blocks including at least 10 torches, stage 5 survive 2 nights, stage 6 collect 10 gold, stage 7 craft a beacon, and stage 8 place the beacon on the pad. woodCollected increases by 1 when a wood item is added, stoneMined increases by 1 when a stone item is added from breaking stone, goldCollected increases by 1 when a gold item is added, pickaxeCrafted becomes true when any pickaxe is crafted, beaconCrafted becomes true when a beacon is crafted, blockValuePlaced and torchesPlaced are updated by BUILDING, and nightsSurvived increases by 1 when time reaches 0 and the player was alive during the previous night. When a stage completes, stage increases by 1 and the quest sound plays. When stage 8 completes, the win condition is met and the game goes to game over with win text.

UI: The HUD record is presentation only and has fields crosshair true and message. UI reads health and hunger from Player, items and selectedSlot from Inventory, stage and progress from Quest, and time from DayNight, and it never stores a second copy of those values. It draws a health bar of 10 hearts, a hunger bar of 10 drumsticks, the 9 hotbar slots, the selected slot frame, the quest text, the day or night clock, a crosshair, and floating damage or pickup numbers. All UI is drawn in code.

SCREENS: title (shows the game name, a start button, and the control list) → game (shows the world, HUD, and crosshair) → pause (shows resume, restart, and title buttons) → inventory (shows the 36 slots, the recipe list, and a close button) → game over (shows win or death text and offers restart and title buttons). Pressing Start or the touch start button leads from title to game. Pressing E or the touch inventory button in game leads to inventory. Pressing Escape in game leads to pause. Pressing Resume or Escape in pause leads back to game. Pressing Restart in pause leads to game with the next World seed. Pressing Title in pause leads to title. Pressing Close, E, or Escape in inventory leads to game. Pressing Restart in game over leads to game with the next World seed. Pressing Title in game over leads to title. Escape in title does nothing, and Escape in game over does nothing.

AUDIO: all sound is generated with the Web Audio API. The sounds are: titleClick when a title button is pressed, start when the game begins, blockBreak when a block breaks, blockPlace when a block is placed, playerHurt when the player takes damage, mobHurt when a mob takes damage, mobDeath when a mob dies, itemPickup when an item is picked up, eat when food is consumed, craft when a recipe succeeds, quest when a quest stage completes, day when time reaches 0, night when time reaches 180, win when stage 8 completes, death when health reaches 0, uiOpen when inventory or pause opens, and uiClose when inventory or pause closes.

ART: ask for the title scene as a scene, ask for the zombie as a sprite, ask for the skeleton as a sprite, ask for the spider as a sprite, ask for the grass block as a tile, ask for the dirt block as a tile, ask for the stone block as a tile, ask for the wood block as a tile, ask for the planks block as a tile, ask for the leaves block as a tile, ask for the sand block as a tile, ask for the water block as a tile, ask for the coal ore block as a tile, ask for the iron ore block as a tile, ask for the gold ore block as a tile, ask for the torch as a sprite, and ask for the beacon block as a tile. Everything else — UI bars, buttons, text, crosshair, particles, shadows, lighting, hotbar frames, quest icons, tool icons, food icons, and mob health bars — is drawn in code.
