Build this four-lane browser rhythm game with procedurally generated music and charts. Every number below is a given value to write into the code as-is; none of them needs checking or deriving.

RECORDS: GAME, SONG, NOTE, PLAYER, MUSIC EVENT, INSTRUMENT, SCALE DEGREE, LANE.

GAME: state starts title and is one of title, playing, paused, results, failed; seed is an integer from 0 to 999999 and starts 0; difficulty is an integer from 1 to 10 and starts 1; songTime in seconds starts 0; lastInputLane is an integer from -1 to 3 and starts -1; lastInputTime in seconds starts 0; inputPending is a boolean and starts false; muted is a boolean and starts false; width in pixels starts 720; height in pixels starts 720; hitLineY in pixels starts 640; noteSpeed in pixels per second starts 320; travelTime in seconds starts 2.0.

SONG: bpm starts 120; beats starts 192; duration in seconds starts 96; stepDuration in seconds starts 0.125; beatDuration in seconds starts 0.5; generated is a boolean and starts false; notesTotal is an integer and starts 0; musicVolume is a number from 0 to 1 and starts 0.8.

NOTE: id is an integer; lane is an integer from 0 to 3; startTime in seconds; y in pixels starts 0; state is one of waiting, active, hit, missed, gone and starts waiting; judgment is one of none, perfect, great, good, miss and starts none; size in pixels starts 80.

PLAYER: score is an integer and starts 0; combo is an integer and starts 0; maxCombo is an integer and starts 0; perfects is an integer and starts 0; greats is an integer and starts 0; goods is an integer and starts 0; misses is an integer and starts 0; health is an integer from 0 to 100 and starts 100; bestScore is an integer and starts 0; bestRank is a string and starts none; unlockedDifficulty is an integer from 1 to 10 and starts 1; rank is a string and starts none.

MUSIC EVENT: id is an integer; time in seconds; instrument is a string one of kick, snare, hat, bass, lead; pitch in semitones from 0 to 12; duration in seconds; velocity is a number from 0 to 1; played is a boolean and starts false.

INSTRUMENT: id is a string; basePitch in hertz; gain from 0 to 1; attack in ms; decay in ms; type is a string one of sine, square, noise. The roster is kick with basePitch 55, gain 1.0, attack 0, decay 180, type sine; snare with basePitch 180, gain 0.7, attack 0, decay 120, type noise; hat with basePitch 6000, gain 0.3, attack 0, decay 40, type noise; bass with basePitch 80, gain 0.5, attack 10, decay 220, type square; lead with basePitch 440, gain 0.45, attack 5, decay 160, type square.

SCALE DEGREE: id is a string; semitones is an integer; weight is an integer. The roster is root with semitones 0 and weight 5, major third with semitones 4 and weight 3, perfect fifth with semitones 7 and weight 3, major sixth with semitones 9 and weight 2, octave with semitones 12 and weight 2.

LANE: id is an integer from 0 to 3; x in pixels; width in pixels. The roster is lane 0 with x 120 and width 120, lane 1 with x 240 and width 120, lane 2 with x 360 and width 120, lane 3 with x 480 and width 120.

SYSTEMS: INPUT, SONG CLOCK, MUSIC GENERATOR, CHART GENERATOR, NOTE MOTION, HIT JUDGMENT, RESULTS AND PROGRESSION, AUDIO SCHEDULER.

INPUT: While GAME.state is playing, a keydown or touchstart maps to a lane: A or LeftArrow sets lane 0, S or DownArrow sets lane 1, D or RightArrow sets lane 2, W or UpArrow sets lane 3, and repeated key events are ignored. Touch uses four equal zones across the bottom 160 pixels of GAME.height: x 0 to 180 is lane 0, 180 to 360 is lane 1, 360 to 540 is lane 2, and 540 to 720 is lane 3. When a valid input arrives, set GAME.inputPending to true, GAME.lastInputLane to that lane, and GAME.lastInputTime to GAME.songTime. While GAME.state is title, A or LeftArrow decreases GAME.difficulty by 1 and D or RightArrow increases GAME.difficulty by 1, clamped to 1 and PLAYER.unlockedDifficulty; W or UpArrow or Enter starts playing. While GAME.state is paused, W or UpArrow or Enter resumes, S or DownArrow restarts, and D or RightArrow returns to title. While GAME.state is results or failed, W or UpArrow or Enter returns to title, S or DownArrow retries the same seed and difficulty, and D or RightArrow returns to title. Escape while playing sets state to paused, Escape while paused sets state to playing, and Escape while results or failed sets state to title; M toggles GAME.muted in any state.

SONG CLOCK: When a song starts or restarts, set GAME.songTime to 0, SONG.generated to false, and reset PLAYER.score, combo, maxCombo, perfects, greats, goods, misses, health, and rank to their starting values. If GAME.seed is greater than 999999, set GAME.seed to 0. While GAME.state is playing, increase GAME.songTime by the real elapsed seconds each frame, never above SONG.duration. Before the first frame of a new song, if SONG.generated is false, run MUSIC GENERATOR and CHART GENERATOR; when both pass, set SONG.generated to true. When GAME.songTime reaches SONG.duration, set GAME.state to results if PLAYER.health is greater than 0, otherwise failed. While GAME.state is paused, GAME.songTime does not increase and no NOTE is moved or missed.

MUSIC GENERATOR: When SONG.generated is false, use GAME.seed to fill MUSIC EVENTs for 48 bars, each bar 2.0 seconds long. For every bar, add kick events at bar start and bar start plus 1.0s with velocity 1.0 and duration 0.180s; add snare events at bar start plus 0.5s and bar start plus 1.5s with velocity 0.9 and duration 0.120s; add hat events at every eighth step, 0.25s apart, with velocity 0.35 and duration 0.040s, and on each off sixteenth step, 0.125s after an eighth, add a hat with probability 0.35, velocity 0.25, and duration 0.040s. Choose one SCALE DEGREE by weight for the bar and add bass events at each beat, 0.5s apart, with pitch equal to the degree's semitones, duration 0.450s, and velocity 0.8. For each of the 8 eighth steps in the bar, add a lead event with probability 0.30, pitch chosen by weight from SCALE DEGREE, duration 0.180s, and velocity 0.6; if the chosen pitch equals the previous lead pitch, reroll once and if still equal use the next SCALE DEGREE in roster order, wrapping to root. The verifier requires every bar to have exactly 2 kicks, exactly 2 snares, at least 8 hats, at least 4 bass notes, and at least 1 lead note; total MUSIC EVENTs must be between 800 and 1600; every time must be from 0s to 96s and every pitch from 0 to 12 semitones. If any check fails, increase GAME.seed by 1 and re-roll with the next seed.

CHART GENERATOR: When SONG.generated is false, use GAME.seed plus 7919 to make NOTEs. Consider candidate times from 2.0s to 94.0s inclusive at 0.25s intervals. For each candidate, roll a probability of 0.15 + GAME.difficulty * 0.025; if it passes, create one NOTE with startTime equal to the candidate, y 0, state waiting, judgment none, and size 80. Choose a lane by seed, but do not choose a lane that received a note at the previous candidate time in that same lane. With probability 0.15 of the successful roll, add a second NOTE at the same time in a different lane, unless two notes already share that time. Set SONG.notesTotal to the count. The verifier requires SONG.notesTotal between 60 and 200, at least one note in each of the four lanes, no two notes in the same lane closer than 0.25s, no more than 2 notes with the same startTime, and every startTime between 2.0s and 94.0s. If any check fails, increase GAME.seed by 1 and re-roll with the next seed.

NOTE MOTION: While GAME.state is playing, for each NOTE with state waiting, if GAME.songTime is at least NOTE.startTime minus GAME.travelTime, set state to active and y to 0. For each NOTE with state active, hit, or missed, set y to (GAME.songTime minus NOTE.startTime plus GAME.travelTime) times GAME.noteSpeed. With the given values, y is 0 at startTime minus 2.0s and 640 at startTime. If y is greater than GAME.height plus 80, set state to gone.

HIT JUDGMENT: While GAME.state is playing, if GAME.inputPending is true, let lane be GAME.lastInputLane and t be GAME.lastInputTime. Consider every NOTE in that lane with state active, judgment none, and absolute difference between t and NOTE.startTime at most 0.120s. If no such NOTE exists, set PLAYER.combo to 0, decrease PLAYER.health by 2, and set GAME.inputPending to false. If one or more candidates exist, choose the candidate with the smallest absolute difference, breaking ties by the earlier NOTE.startTime. Set the chosen NOTE.state to hit. Set NOTE.judgment to perfect if the absolute difference is at most 0.030s, great if it is at most 0.075s, or good if it is at most 0.120s. Increase the matching PLAYER count by 1. Increase PLAYER.score by the judgment base plus PLAYER.combo times 2, where the base is 100 for perfect, 70 for great, and 40 for good. Increase PLAYER.combo by 1, and if the new combo is greater than PLAYER.maxCombo, set PLAYER.maxCombo to the new combo. Increase PLAYER.health by 2 for perfect, 1 for great, and 0 for good. Clamp PLAYER.health to 0 and 100. Set GAME.inputPending to false. Every frame while playing, for each NOTE with state active, if GAME.songTime is greater than NOTE.startTime plus 0.120s, set NOTE.state to missed, set NOTE.judgment to miss, increase PLAYER.misses by 1, set PLAYER.combo to 0, and decrease PLAYER.health by 8. If two notes share the same startTime in different lanes, each is judged and missed independently. If a missed note is in a lane that also has a hit note at the same time, the miss does not cancel the hit. If PLAYER.health is 0 or less after any health change, set GAME.state to failed. While paused, input and auto-miss rules do not run.

RESULTS AND PROGRESSION: When GAME.state becomes results, set PLAYER.rank to S if PLAYER.misses is 0 and PLAYER.health is at least 90, A if PLAYER.health is at least 70, B if PLAYER.health is at least 50, C if PLAYER.health is at least 30, D if PLAYER.health is greater than 0, and F otherwise. Increase PLAYER.score by 1000 for S, 500 for A, 200 for B, 50 for C, and 0 for D or F. If PLAYER.score is greater than PLAYER.bestScore, set PLAYER.bestScore to PLAYER.score. Update PLAYER.bestRank if PLAYER.rank is better than PLAYER.bestRank, with order S, A, B, C, D, F. If PLAYER.rank is S, A, or B, GAME.difficulty equals PLAYER.unlockedDifficulty, and PLAYER.unlockedDifficulty is less than 10, increase PLAYER.unlockedDifficulty by 1. When GAME.state becomes failed, set PLAYER.rank to F, do not increase score bonus, and do not unlock a difficulty.

AUDIO SCHEDULER: While GAME.state is playing, every 0.05s, schedule any MUSIC EVENT with played false whose time is between GAME.songTime minus 0.010s and GAME.songTime plus 0.200s, then set played to true. For each scheduled event, use the INSTRUMENT roster: kick is a sine oscillator, snare and hat are noise bursts, bass and lead are square oscillators; set gain to INSTRUMENT.gain times MUSIC EVENT.velocity times SONG.musicVolume, attack to INSTRUMENT.attack ms, decay to INSTRUMENT.decay ms, and pitch to INSTRUMENT.basePitch times 2 to the power of MUSIC EVENT.pitch divided by 12. If GAME.muted is true, set all gains to 0. When HIT JUDGMENT sets a judgment, play a short blip: perfect 880Hz gain 0.5 decay 0.050s, great 660Hz gain 0.45 decay 0.050s, good 440Hz gain 0.4 decay 0.060s, miss 110Hz gain 0.5 decay 0.200s. Play a 520Hz UI blip with gain 0.3 and decay 0.040s on menu select, and play an 80Hz fail tone with gain 0.6 and decay 0.400s when GAME.state becomes failed.

CORE LOOP: The player chooses a difficulty in INPUT, starts a song where SONG CLOCK begins, MUSIC GENERATOR and CHART GENERATOR build the track and notes, NOTE MOTION makes notes fall, and HIT JUDGMENT turns each timed press into score, combo, and health. A good run keeps health high and combo growing, while misses and stray presses drain health and force a failed state. RESULTS AND PROGRESSION then awards a rank, updates best score and best rank, and can unlock the next difficulty, so the player repeats with a denser chart to chase S rank, higher score, and the full difficulty ladder.

SCREENS: The game is a state machine of title, playing, paused, results, and failed. Title shows the name FOUR BEAT, PLAYER.bestScore, PLAYER.bestRank, a difficulty selector limited to PLAYER.unlockedDifficulty, and a Start button; Enter or Start begins playing with GAME.seed set to a random integer from 0 to 999999 and GAME.difficulty set to the selected value. Playing shows the four LANE columns, falling NOTE sprites, the hit line at GAME.hitLineY, and a HUD reading PLAYER.score, PLAYER.combo, PLAYER.health, GAME.songTime over SONG.duration, and GAME.difficulty. Escape while playing opens paused, which offers Resume, Restart, and Menu; Resume returns to playing, Restart regenerates with the same seed and difficulty, and Menu returns to title. When the song ends, results shows PLAYER.rank, PLAYER.score, perfects, greats, goods, misses, maxCombo, and any unlock message; Enter or Menu returns to title, and Retry uses the same seed and difficulty. If health reaches zero, failed shows the same counts and offers Retry or Menu; Retry uses the same seed and difficulty. Escape while paused returns to playing, and Escape while results or failed returns to title.

AUDIO: All sound is generated with the Web Audio API. The music is a layered procedural track: kick is a 55Hz sine with 0.180s decay, snare is a 180Hz noise burst with 0.120s decay, hat is a 6000Hz noise burst with 0.040s decay, bass is a square oscillator at 80Hz plus the event pitch with 0.220s decay, and lead is a square oscillator at 440Hz plus the event pitch with 0.160s decay; each event plays when its MUSIC EVENT.time is reached during SONG CLOCK. Hit sounds play when HIT JUDGMENT sets a judgment: perfect is an 880Hz blip with 0.050s decay, great is 660Hz with 0.050s decay, good is 440Hz with 0.060s decay, miss is a 110Hz buzz with 0.200s decay. Menu select is a 520Hz blip with 0.040s decay, and fail is an 80Hz tone with 0.400s decay when GAME.state becomes failed.

ART: Ask for a neon arcade title scene as a scene, a red note sprite as a sprite, a cyan note sprite as a sprite, a green note sprite as a sprite, a yellow note sprite as a sprite, and a dark lane tile as a tile. The title scene is the background for title and results; the four note sprites are used for lanes 0 through 3; the lane tile is repeated for each LANE. Everything else — lane separators, hit line, judgment text, score numbers, combo, health bar, note trails, particles, buttons, and rank letters — is drawn in code.
